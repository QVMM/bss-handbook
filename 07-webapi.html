01接口是什么，为什么手机不能直接连数据库

想象一个餐厅：数据库是后厨，手机 App 是顾客。顾客不能自己进后厨拿菜，而是向服务员点菜，服务员去后厨取来再端给顾客。接口（API）就是服务员：它规定了“能点什么菜（有哪些地址）”“怎么点（发送什么数据）”“端上来是什么样（返回什么数据）”。

 ┌──────────────┐   HTTP 请求（URL + JSON）   ┌──────────────┐    SQL     ┌──────────────┐
 │ 手机 App      │ ─────────────────────────▶ │  Web API     │ ─────────▶ │ SQL Server   │
 │ (模块 B)      │ ◀───────────────────────── │  (模块 A 中)  │ ◀───────── │  SmartCare   │
 └──────────────┘      HTTP 响应（JSON）       └──────────────┘   数据     └──────────────┘
                                                  ▲
                         桌面端 WinForms 直接连数据库（第 06 章）

手机不直接连数据库的原因：① Android 上没有可用的 SQL Server 驱动（也不应该把数据库密码放在手机里）；② 接口可以统一做校验和权限控制；③ 同一个接口可以同时给手机、网页、小程序用。这正是企业里的真实做法，也是比赛考查的能力点（辽宁能力目录中明确列有 WebAPI）。

JSON 的语法

JSON 只有六种值：字符串（双引号）、数字、true/false、null、对象 { }、数组 [ ]。对象是“键: 值”的集合，键必须用双引号。

03先设计，再编码：接口文档

动手写代码之前，先写一份接口文档。比赛时这份文档就是你自己做模块 B 的“说明书”，也是交付物里体现专业度的部分（湖北样题模块 B 提供了 WebAPI_technical.pdf，就是这类文档）。本手册的练习接口约定如下（这是本手册自拟的约定，比赛中如果题目给了接口文档，严格按题目来）：

  • 基础地址：http://localhost:5000
  • 所有返回统一为 { "success": 布尔, "message": 文字, "data": 数据 }
  • 字段名用小驼峰（serviceName），日期时间统一为 yyyy-MM-dd HH:mm:ss，日期为 yyyy-MM-dd
  • POST 请求体为 JSON，编码 UTF-8

训练建议：为什么要统一返回结构

如果有的接口返回数组、有的返回对象、失败时又返回一段文字，手机端每个页面都要写不同的解析代码，非常容易出错。统一成 success/message/data 后，手机端只写一个通用方法：先看 success，失败就把 message 弹出来，成功再取 data。这样连错误提示都是现成的。

04方案一：零依赖的 HttpListener 接口（保底方案）

这个方案只用 .NET Framework 自带的类，不需要安装任何 NuGet 包、不需要 IIS，在完全断网的电脑上也一定能建出来。比赛断网是常态，所以本手册把它作为必须掌握的保底方案。

建项目

  1. 在 Modul1 解决方案上右键 → 添加 → 新建项目 → “控制台应用(.NET Framework)”，名称 SmartCareApi，框架 4.8。
  2. 添加引用：System.Web.Extensions（JSON 序列化）、System.Configuration（读连接字符串）。
  3. App.config 中加入与桌面端相同的 connectionStrings 节（见第 06 章）。
  4. 把桌面端的 DbHelper.cs 复制过来，命名空间改为 SmartCareApi。

JSON 工具类

.NET Framework 自带的 JavaScriptSerializer 有个坑：直接序列化 DateTime 会输出 "\/Date(1727740800000)\/" 这样的格式，手机端很难处理。下面的工具类把查询结果逐行转换成字典，日期统一转成字符串，字段名统一转成小驼峰：

Json.cs
using System;
using System.Collections.Generic;
using System.Data;
using System.Web.Script.Serialization;

namespace SmartCareApi
{
    /// <summary>JSON 工具：只用 .NET Framework 自带的 JavaScriptSerializer（引用 System.Web.Extensions）。</summary>
    public static class Json
    {
        private static readonly JavaScriptSerializer Serializer = new JavaScriptSerializer { MaxJsonLength = int.MaxValue };

        public static string Stringify(object obj) { return Serializer.Serialize(obj); }

        public static Dictionary<string, object> Parse(string json)
        {
            if (string.IsNullOrWhiteSpace(json)) return new Dictionary<string, object>();
            return Serializer.Deserialize<Dictionary<string, object>>(json);
        }

        /// <summary>
        /// DataTable 转成“字典列表”。日期统一转成 yyyy-MM-dd HH:mm:ss 字符串，
        /// DBNull 转成 null，避免 JavaScriptSerializer 输出 /Date(...)/ 这种手机端难以解析的格式。
        /// </summary>
        public static List<Dictionary<string, object>> Rows(DataTable dt)
        {
            List<Dictionary<string, object>> list = new List<Dictionary<string, object>>();
            foreach (DataRow r in dt.Rows)
            {
                Dictionary<string, object> d = new Dictionary<string, object>();
                foreach (DataColumn c in dt.Columns)
                {
                    object v = r[c];
                    if (v == DBNull.Value) v = null;
                    else if (v is DateTime) v = ((DateTime)v).ToString("yyyy-MM-dd HH:mm:ss");
                    d[ToCamel(c.ColumnName)] = v;
                }
                list.Add(d);
            }
            return list;
        }

        // ServiceName -> serviceName：JSON 字段统一用小驼峰
        private static string ToCamel(string s)
        {
            return string.IsNullOrEmpty(s) ? s : char.ToLowerInvariant(s[0]) + s.Substring(1);
        }

        /// <summary>统一的返回结构：{ "success": true/false, "message": "...", "data": ... }</summary>
        public static string Ok(object data) { return Stringify(new { success = true, message = "成功", data = data }); }
        public static string Fail(string message) { return Stringify(new { success = false, message = message, data = (object)null }); }
    }
}

接口服务

ApiServer.cs
using System;
using System.Collections.Generic;
using System.Data;
using System.Data.SqlClient;
using System.IO;
using System.Net;
using System.Text;

namespace SmartCareApi
{
    /// <summary>
    /// 零依赖的 HTTP 接口服务：只用 .NET Framework 自带的 HttpListener，不需要任何 NuGet 包。
    /// </summary>
    public class ApiServer
    {
        private readonly HttpListener _listener = new HttpListener();

        public ApiServer(string prefix)          // 例如 "http://localhost:5000/"
        {
            _listener.Prefixes.Add(prefix);
        }

        public void Start()
        {
            _listener.Start();
            while (true)
            {
                HttpListenerContext ctx = _listener.GetContext();   // 等待下一个请求
                try { Handle(ctx); }
                catch (Exception ex) { Write(ctx, 500, Json.Fail("服务器错误：" + ex.Message)); }
            }
        }

        private void Handle(HttpListenerContext ctx)
        {
            HttpListenerRequest req = ctx.Request;
            string method = req.HttpMethod.ToUpperInvariant();
            string path = req.Url.AbsolutePath.TrimEnd('/').ToLowerInvariant();
            Console.WriteLine(DateTime.Now.ToString("HH:mm:ss") + "  " + method + " " + req.Url.PathAndQuery);

            if (method == "OPTIONS") { Write(ctx, 200, ""); return; }

            string body = "";
            if (req.HasEntityBody)
                using (StreamReader sr = new StreamReader(req.InputStream, Encoding.UTF8)) body = sr.ReadToEnd();

            // ---------- 路由表：方法 + 路径 -> 处理函数 ----------
            if (method == "POST" && path == "/api/customer/login")          { Write(ctx, 200, Login(Json.Parse(body))); return; }
            if (method == "POST" && path == "/api/customer/loginbycode")    { Write(ctx, 200, LoginByCode(Json.Parse(body))); return; }
            if (method == "POST" && path == "/api/customer/register")       { Write(ctx, 200, Register(Json.Parse(body))); return; }
            if (method == "GET"  && path == "/api/categories")              { Write(ctx, 200, Categories()); return; }
            if (method == "GET"  && path == "/api/services")                { Write(ctx, 200, Services(req.QueryString["keyword"], req.QueryString["categoryId"])); return; }
            if (method == "POST" && path == "/api/orders")                  { Write(ctx, 200, CreateOrder(Json.Parse(body))); return; }
            if (method == "GET"  && path == "/api/orders")                  { Write(ctx, 200, Orders(req.QueryString["customerId"])); return; }
            if (method == "POST" && path == "/api/orders/cancel")           { Write(ctx, 200, CancelOrder(Json.Parse(body))); return; }
            if (method == "POST" && path == "/api/customer/resetpassword")  { Write(ctx, 200, ResetPassword(Json.Parse(body))); return; }
            if (method == "GET"  && path == "/api/health")                  { Write(ctx, 200, Health(req.QueryString["customerId"], req.QueryString["type"])); return; }
            if (method == "GET"  && path == "/api/contacts")                { Write(ctx, 200, Contacts(req.QueryString["customerId"])); return; }

            Write(ctx, 404, Json.Fail("接口不存在：" + method + " " + path));
        }

        private static void Write(HttpListenerContext ctx, int status, string json)
        {
            byte[] buf = Encoding.UTF8.GetBytes(json);
            ctx.Response.StatusCode = status;
            ctx.Response.ContentType = "application/json; charset=utf-8";
            ctx.Response.AddHeader("Access-Control-Allow-Origin", "*");
            ctx.Response.ContentLength64 = buf.Length;
            ctx.Response.OutputStream.Write(buf, 0, buf.Length);
            ctx.Response.OutputStream.Close();
        }

        private static string Str(Dictionary<string, object> d, string key)
        {
            object v;
            return d.TryGetValue(key, out v) && v != null ? v.ToString().Trim() : "";
        }

        // POST /api/customer/login   请求：{ "phone": "...", "password": "..." }
        private string Login(Dictionary<string, object> p)
        {
            string phone = Str(p, "phone"), pwd = Str(p, "password");
            if (phone == "" || pwd == "") return Json.Fail("手机号和密码不能为空");
            DataTable dt = DbHelper.Query(
                "SELECT CustomerId, Phone, RealName, Gender, CONVERT(CHAR(10), BirthDate, 120) AS BirthDate, Address, Avatar, Status FROM Customer WHERE Phone = @ph AND Password = @pw",
                new SqlParameter("@ph", phone), new SqlParameter("@pw", pwd));
            if (dt.Rows.Count == 0) return Json.Fail("手机号或密码错误");
            if (Convert.ToInt32(dt.Rows[0]["Status"]) == 0) return Json.Fail("该账号已被禁用");
            return Json.Ok(Json.Rows(dt)[0]);
        }

        // POST /api/customer/loginByCode   请求：{ "phone": "..." }
        // 练习约定：验证码由手机端模拟生成和校验，校验通过后调用本接口按手机号取回客户信息。
        // 真实系统中验证码必须由服务器生成、发送和校验，这里只是比赛中“模拟”的简化做法。
        private string LoginByCode(Dictionary<string, object> p)
        {
            string phone = Str(p, "phone");
            DataTable dt = DbHelper.Query(
                "SELECT CustomerId, Phone, RealName, Gender, CONVERT(CHAR(10), BirthDate, 120) AS BirthDate, Address, Avatar, Status FROM Customer WHERE Phone = @ph",
                new SqlParameter("@ph", phone));
            if (dt.Rows.Count == 0) return Json.Fail("该手机号未注册");
            if (Convert.ToInt32(dt.Rows[0]["Status"]) == 0) return Json.Fail("该账号已被禁用");
            return Json.Ok(Json.Rows(dt)[0]);
        }

        // POST /api/customer/register   请求：{ "phone": "...", "password": "..." }
        private string Register(Dictionary<string, object> p)
        {
            string phone = Str(p, "phone"), pwd = Str(p, "password");
            if (phone.Length != 11) return Json.Fail("手机号必须是 11 位");
            if (pwd.Length < 8) return Json.Fail("密码至少 8 位");
            int n = Convert.ToInt32(DbHelper.Scalar("SELECT COUNT(*) FROM Customer WHERE Phone = @ph", new SqlParameter("@ph", phone)));
            if (n > 0) return Json.Fail("该手机号已注册");
            object id = DbHelper.Scalar(
                "INSERT INTO Customer (Phone, Password) VALUES (@ph, @pw); SELECT CAST(SCOPE_IDENTITY() AS INT);",
                new SqlParameter("@ph", phone), new SqlParameter("@pw", pwd));
            return Json.Ok(new { customerId = Convert.ToInt32(id) });
        }

        // GET /api/categories
        private string Categories()
        {
            return Json.Ok(Json.Rows(DbHelper.Query("SELECT CategoryId, CategoryName FROM ServiceCategory ORDER BY CategoryId")));
        }

        // GET /api/services?keyword=助&categoryId=1    两个参数都可省略；只返回在售服务
        private string Services(string keyword, string categoryId)
        {
            string sql = @"SELECT s.ServiceId, s.ServiceName, s.Price, s.DurationMinutes, s.Description, s.ImageName,
                                  c.CategoryId, c.CategoryName
                           FROM CareService s JOIN ServiceCategory c ON s.CategoryId = c.CategoryId
                           WHERE s.IsOnSale = 1";
            List<SqlParameter> ps = new List<SqlParameter>();
            if (!string.IsNullOrWhiteSpace(keyword))
            {
                sql += " AND s.ServiceName LIKE @kw";
                ps.Add(new SqlParameter("@kw", "%" + keyword.Trim() + "%"));
            }
            int cid;
            if (int.TryParse(categoryId, out cid) && cid > 0)
            {
                sql += " AND s.CategoryId = @cid";
                ps.Add(new SqlParameter("@cid", SqlDbType.Int) { Value = cid });
            }
            sql += " ORDER BY s.ServiceId";
            return Json.Ok(Json.Rows(DbHelper.Query(sql, ps.ToArray())));
        }

        // POST /api/orders   请求：{ "customerId": 1, "serviceId": 2, "quantity": 1, "appointmentTime": "2026-12-01 09:00:00" }
        private string CreateOrder(Dictionary<string, object> p)
        {
            int customerId, serviceId, qty;
            DateTime time;
            if (!int.TryParse(Str(p, "customerId"), out customerId) || !int.TryParse(Str(p, "serviceId"), out serviceId))
                return Json.Fail("缺少客户或服务编号");
            if (!int.TryParse(Str(p, "quantity"), out qty) || qty <= 0) return Json.Fail("数量必须是正整数");
            if (!DateTime.TryParse(Str(p, "appointmentTime"), out time)) return Json.Fail("预约时间格式应为 yyyy-MM-dd HH:mm:ss");
            if (time <= DateTime.Now) return Json.Fail("预约时间必须晚于当前时间");

            object price = DbHelper.Scalar("SELECT Price FROM CareService WHERE ServiceId = @id AND IsOnSale = 1",
                new SqlParameter("@id", SqlDbType.Int) { Value = serviceId });
            if (price == null) return Json.Fail("服务不存在或已下架");
            decimal amount = Convert.ToDecimal(price) * qty;
            string orderNo = "SO" + DateTime.Now.ToString("yyyyMMddHHmmssfff");

            object id = DbHelper.Scalar(@"INSERT INTO ServiceOrder (OrderNo, CustomerId, ServiceId, Quantity, Amount, AppointmentTime)
                                          VALUES (@no, @c, @s, @q, @a, @t); SELECT CAST(SCOPE_IDENTITY() AS INT);",
                new SqlParameter("@no", orderNo),
                new SqlParameter("@c", SqlDbType.Int) { Value = customerId },
                new SqlParameter("@s", SqlDbType.Int) { Value = serviceId },
                new SqlParameter("@q", SqlDbType.Int) { Value = qty },
                new SqlParameter("@a", SqlDbType.Decimal) { Value = amount, Precision = 10, Scale = 2 },
                new SqlParameter("@t", SqlDbType.DateTime) { Value = time });
            return Json.Ok(new { orderId = Convert.ToInt32(id), orderNo = orderNo, amount = amount });
        }

        // GET /api/orders?customerId=1
        private string Orders(string customerId)
        {
            int cid;
            if (!int.TryParse(customerId, out cid)) return Json.Fail("缺少 customerId");
            DataTable dt = DbHelper.Query(@"SELECT o.OrderId, o.OrderNo, s.ServiceName, o.Quantity, o.Amount,
                                                   o.AppointmentTime, o.Status, o.CreatedAt
                                            FROM ServiceOrder o JOIN CareService s ON o.ServiceId = s.ServiceId
                                            WHERE o.CustomerId = @c ORDER BY o.CreatedAt DESC",
                new SqlParameter("@c", SqlDbType.Int) { Value = cid });
            return Json.Ok(Json.Rows(dt));
        }

        // POST /api/orders/cancel   请求：{ "orderId": 30, "customerId": 1 }   只能取消自己的、待支付或已支付的订单
        private string CancelOrder(Dictionary<string, object> p)
        {
            int orderId, customerId;
            if (!int.TryParse(Str(p, "orderId"), out orderId) || !int.TryParse(Str(p, "customerId"), out customerId))
                return Json.Fail("缺少订单或客户编号");
            int n = DbHelper.Execute("UPDATE ServiceOrder SET Status = 3 WHERE OrderId = @o AND CustomerId = @c AND Status IN (0, 1)",
                new SqlParameter("@o", SqlDbType.Int) { Value = orderId },
                new SqlParameter("@c", SqlDbType.Int) { Value = customerId });
            return n == 1 ? Json.Ok(null) : Json.Fail("订单不存在或当前状态不能取消");
        }

        // POST /api/customer/resetPassword   请求：{ "phone": "...", "newPassword": "..." }
        // 验证码在手机端模拟校验，接口只负责改密码
        private string ResetPassword(Dictionary<string, object> p)
        {
            string phone = Str(p, "phone"), pwd = Str(p, "newPassword");
            if (pwd.Length < 8) return Json.Fail("密码至少 8 位");
            int n = DbHelper.Execute("UPDATE Customer SET Password = @pw WHERE Phone = @ph",
                new SqlParameter("@pw", pwd), new SqlParameter("@ph", phone));
            return n == 1 ? Json.Ok(null) : Json.Fail("该手机号未注册");
        }

        // GET /api/health?customerId=1&type=血压    type 可省略；按测量时间升序，方便画折线
        private string Health(string customerId, string type)
        {
            int cid;
            if (!int.TryParse(customerId, out cid)) return Json.Fail("缺少 customerId");
            string sql = "SELECT RecordId, RecordType, Value1, Value2, MeasuredAt FROM HealthRecord WHERE CustomerId = @c";
            List<SqlParameter> ps = new List<SqlParameter> { new SqlParameter("@c", SqlDbType.Int) { Value = cid } };
            if (!string.IsNullOrWhiteSpace(type))
            {
                sql += " AND RecordType = @t";
                ps.Add(new SqlParameter("@t", type.Trim()));
            }
            sql += " ORDER BY MeasuredAt";
            return Json.Ok(Json.Rows(DbHelper.Query(sql, ps.ToArray())));
        }

        // GET /api/contacts?customerId=1   紧急联系人
        private string Contacts(string customerId)
        {
            int cid;
            if (!int.TryParse(customerId, out cid)) return Json.Fail("缺少 customerId");
            return Json.Ok(Json.Rows(DbHelper.Query(
                "SELECT ContactId, ContactName, Phone, Relation FROM EmergencyContact WHERE CustomerId = @c ORDER BY ContactId",
                new SqlParameter("@c", SqlDbType.Int) { Value = cid })));
        }
    }
}

05方案二：ASP.NET Web API 2（标准方案）

ASP.NET Web API 2 是 .NET Framework 上的标准接口框架，路由、参数绑定、JSON 序列化都由框架完成，代码更简洁，也更“像企业项目”。前提是：Visual Studio 安装了“ASP.NET 和 Web 开发”工作负载，且项目模板所需的 NuGet 包能够还原（模板创建项目时会引用 Microsoft.AspNet.WebApi 等包）。在熟悉设备时，务必在赛场电脑上试建一次 Web API 项目，确认能编译运行；不能，就用方案一。

建项目

  1. 添加新项目 → “ASP.NET Web 应用程序(.NET Framework)” → 名称 SmartCareWebApi，框架 4.8 → 模板选“Web API”（或选“空”并勾选“Web API”）。
  2. 项目属性 → Web → 项目 URL 改为 http://localhost:5000/，点“创建虚拟目录”。这样地址固定，手机端不用跟着改。
  3. 添加引用 System.Configuration（通常已有），Web.config 的 <connectionStrings> 中加入 SmartCare 连接字符串，复制 DbHelper。

配置：只返回 JSON、小驼峰、统一日期

打开 App_Start\WebApiConfig.cs，替换为：

App_Start\WebApiConfig.cs
using System.Web.Http;
using Newtonsoft.Json.Serialization;

namespace SmartCareApi
{
    public static class WebApiConfig
    {
        public static void Register(HttpConfiguration config)
        {
            config.MapHttpAttributeRoutes();
            config.Routes.MapHttpRoute(
                name: "DefaultApi",
                routeTemplate: "api/{controller}/{id}",
                defaults: new { id = RouteParameter.Optional });

            // 只返回 JSON：去掉 XML 格式化器，浏览器里看到的也是 JSON
            config.Formatters.Remove(config.Formatters.XmlFormatter);
            var json = config.Formatters.JsonFormatter.SerializerSettings;
            json.ContractResolver = new CamelCasePropertyNamesContractResolver();   // 字段名小驼峰
            json.DateFormatString = "yyyy-MM-dd HH:mm:ss";                          // 统一日期格式
        }
    }
}

控制器

在 Controllers 文件夹添加“Web API 2 控制器 - 空”：

Controllers\CustomerController.cs
using System;
using System.Data;
using System.Data.SqlClient;
using System.Web.Http;

namespace SmartCareApi.Controllers
{
    public class LoginRequest
    {
        public string Phone { get; set; }
        public string Password { get; set; }
    }

    [RoutePrefix("api/customer")]
    public class CustomerController : ApiController
    {
        // POST api/customer/login
        [HttpPost, Route("login")]
        public ApiResult Login([FromBody] LoginRequest req)
        {
            if (req == null || string.IsNullOrWhiteSpace(req.Phone) || string.IsNullOrWhiteSpace(req.Password))
                return ApiResult.Fail("手机号和密码不能为空");
            DataTable dt = DbHelper.Query(
                @"SELECT CustomerId, Phone, RealName, Gender, CONVERT(CHAR(10), BirthDate, 120) AS BirthDate,
                         Address, Avatar, Status
                  FROM Customer WHERE Phone = @ph AND Password = @pw",
                new SqlParameter("@ph", req.Phone.Trim()), new SqlParameter("@pw", req.Password));
            if (dt.Rows.Count == 0) return ApiResult.Fail("手机号或密码错误");
            if (Convert.ToInt32(dt.Rows[0]["Status"]) == 0) return ApiResult.Fail("该账号已被禁用");
            return ApiResult.Ok(ToDict(dt.Rows[0]));   // 单条记录返回对象，和 HttpListener 版保持一致
        }

        /// <summary>把一行数据转成字典；配合小驼峰设置，键名会输出为 customerId、realName……</summary>
        private static System.Collections.Generic.Dictionary<string, object> ToDict(DataRow r)
        {
            var d = new System.Collections.Generic.Dictionary<string, object>();
            foreach (DataColumn c in r.Table.Columns) d[c.ColumnName] = r[c] == DBNull.Value ? null : r[c];
            return d;
        }
    }

    public class ServicesController : ApiController
    {
        // GET api/services?keyword=助&categoryId=1
        [HttpGet, Route("api/services")]
        public ApiResult Get(string keyword = null, int categoryId = 0)
        {
            string sql = @"SELECT s.ServiceId, s.ServiceName, s.Price, s.DurationMinutes, s.ImageName, c.CategoryName
                           FROM CareService s JOIN ServiceCategory c ON s.CategoryId = c.CategoryId
                           WHERE s.IsOnSale = 1
                             AND (@kw IS NULL OR s.ServiceName LIKE '%' + @kw + '%')
                             AND (@cid = 0 OR s.CategoryId = @cid)
                           ORDER BY s.ServiceId";
            DataTable dt = DbHelper.Query(sql,
                new SqlParameter("@kw", SqlDbType.NVarChar, 50) { Value = (object)keyword ?? DBNull.Value },
                new SqlParameter("@cid", SqlDbType.Int) { Value = categoryId });
            return ApiResult.Ok(dt);     // Json.NET 会把 DataTable 序列化为对象数组
        }
    }
}

对比方案一可以看出：Web API 2 自动把请求体 JSON 绑定到 LoginRequest 对象（属性名不区分大小写），自动把返回对象序列化为 JSON；[Route] 特性直接写出地址。其余接口请你仿照完成（练习 7-3）。

易错提醒：IIS Express 的 400 Bad Request

IIS Express 默认只接受主机名为 localhost 的请求。模拟器用 10.0.2.2:5000 访问时，请求头中的主机名是 10.0.2.2，IIS Express 会直接返回“Bad Request - Invalid Hostname”。HttpListener 绑定 localhost 时也有同样的限制。最省事的解决办法是下一节的 adb reverse：让手机也用 localhost 访问。

06测试接口：浏览器、curl 与一个小技巧

GET 接口：浏览器直接打开

接口启动后，在浏览器地址栏输入 http://localhost:5000/api/services?categoryId=1，能看到 JSON 就说明接口、数据库、连接字符串全部正常。用练习库测试，应返回生活照料类的 3 个在售服务（上门助浴 120.00、助餐配送 25.00、居家保洁 80.00）。

POST 接口：curl.exe

Windows 10 及以上自带 curl.exe。在命令提示符（cmd）中，JSON 里的双引号需要转义，很容易写错。技巧：把请求体写在文件里：

login.json（用记事本保存为 UTF-8）
{"phone":"13800000001","password":"abc12345"}
命令提示符
curl.exe -X POST http://localhost:5000/api/customer/login -H "Content-Type: application/json" --data-binary @login.json

预期返回（练习库数据）：

07让模拟器访问电脑上的接口

Android 模拟器是一台独立的虚拟手机，在模拟器里 localhost 指的是模拟器自己，不是你的电脑。有两种办法：

办法手机端地址说明
A. 特殊地址 10.0.2.2（官方文档说明的模拟器网络地址）http://10.0.2.2:5000/10.0.2.2 在模拟器中代表电脑的回环地址。但请求的主机名变成 10.0.2.2，IIS Express 和绑定 localhost 的 HttpListener 会返回 400
B. 端口反向映射（推荐）http://localhost:5000/在电脑上执行一次 adb reverse tcp:5000 tcp:5000，模拟器访问自己的 5000 端口就会被转到电脑的 5000 端口，主机名仍是 localhost，两种接口方案都不用改
命令提示符（模拟器启动后执行）
D:\Android\Sdk\platform-tools\adb.exe devices
D:\Android\Sdk\platform-tools\adb.exe reverse tcp:5000 tcp:5000
D:\Android\Sdk\platform-tools\adb.exe reverse --list
  • adb devices 应列出 emulator-5554 device；列表为空说明模拟器还没启动好。
  • 模拟器每次重启（或冷启动）后，映射会失效，要重新执行。把这三行保存成 映射端口.bat 放在桌面，双击即可。
  • SDK 路径以你自己的安装位置为准（Android Studio → Settings → Languages & Frameworks → Android SDK 顶部可以看到）。
验证

模拟器中打开自带浏览器，访问 http://localhost:5000/api/categories，能看到 JSON 即为成功。看不到时按顺序排查：接口窗口是否开着 → 电脑浏览器能否访问 → adb reverse 是否执行 → 端口号是否一致。

09拓展练习

练习 7-3　用 Web API 2 实现全部接口

以方案二为基础，把接口文档中其余接口全部实现，然后用练习 7-2 的清单逐条测试，结果必须与方案一完全一致（字段名、日期格式、提示文字）。

提示

POST 接口为每种请求体建一个类（如 OrderRequest：CustomerId、ServiceId、Quantity、AppointmentTime 字符串）；GET 参数直接写成方法参数，可空的写默认值；返回一行数据时用 ToDict(dt.Rows[0])，返回多行直接返回 DataTable。

练习 7-4　新增接口：健康数据上报与统计

① POST /api/health：请求体 {"customerId":1,"recordType":"血压","value1":135,"value2":85}，测量时间取服务器当前时间；校验：类型只能是血压/血糖/心率，血压必须有 value2，数值范围自定并在接口文档中写明。② GET /api/health/summary?customerId=1：按类型返回记录数、最高值、最低值、平均值（保留 1 位小数）、最近一次测量时间。用练习库核对：客户 1 的血压 value1 最高 145.0，最低 128.0。

练习 7-5　按别人的接口文档写接口

解压资料包中的匈牙利 WorldSkills 2024 选拔赛第一轮压缩包，阅读英文题目 PDF 和 assets 文件夹中的 Postman 测试集合（.json 文件，可以用记事本打开，重点看每个请求下的 test 脚本）。回答：① 一共几个接口，各用什么方法和路径？基础地址的端口是多少？② 登录成功和失败时分别返回什么状态码、什么内容？③ 线路列表接口要求返回多少条、按什么顺序？然后用本章的方法实现这些接口（数据库脚本是 MySQL 格式，转换方法见第 12 章），用 curl.exe 逐条验证与测试集合的预期一致。

提示

这套题的返回格式和本手册的练习约定不同：它没有 success/message/data 外壳，登录成功只返回状态码、不返回内容，失败返回带 error 字段的对象并配合 401 状态码。比赛中永远以题目文档为准，不要套用自己习惯的格式——这正是本练习要训练的。HttpListener 方案中设置状态码用 ctx.Response.StatusCode，Web API 2 中可以返回 StatusCode(HttpStatusCode.NoContent) 或 Content(HttpStatusCode.Unauthorized, 对象)。
