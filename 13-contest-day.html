第 13 章 · 训练与实战

赛前与比赛当天

比赛当天你不会再学到新东西，能决定成绩的，是你能否把训练中的水平完整发挥出来。本章包括：赛前一周的安排、熟悉设备那 1 小时要检查什么、每个模块开场 10 分钟怎么做、比赛中的时间控制与应急处理、最后 15 分钟的收尾流程。规则部分依据辽宁技术文件，其余为训练建议；你所参加比赛的规则以该赛事的技术文件和赛场通知为准。

01赛前一周

  • 不学新内容，不改变已经练熟的写法（例如不要临时从 HttpListener 换成别的接口方案）
  • 每天 1–2 次限时小练，保持手感：登录 + 记住密码、查询 + 分页、接口 + 手机端列表、10 条测试用例
  • 把错题本从头到尾读一遍，重点看“会但忘了”一类
  • 默写一遍核心代码骨架：DbHelper、分页 SQL、ApiClient、Adapter、验证码倒计时
  • 重读你所参加比赛的技术文件：模块时长、分值、交付命名、禁带物品清单
  • 准备证件：辽宁文件规定选手赛前 30 分钟凭参赛证和身份证检录
  • 作息调整到比赛时段：比赛几点开始，这一周就几点开始做题

02熟悉设备：最重要的一小时

官方文件怎么说

辽宁文件规定：赛场提供不少于 1 小时的熟悉设备（场地）时间，熟悉设备期间禁止修改竞赛设备参数。

来源：资料包中辽宁省 2026 年技术文件“竞赛流程”部分

这一小时不是“看看电脑长什么样”，而是排查所有可能让你在比赛中卡住的环境问题。按下面的清单逐项确认（只检查、不修改设备参数；发现问题举手报告）：

熟悉设备检查清单

#检查项怎么检查有问题怎么办（建议）
1各软件版本VS、SSMS 帮助 → 关于；Android Studio Help → About记下版本，比赛中避免用该版本不支持的功能
2SQL Server 实例名与身份验证SSMS 连接：先试 .，再试 .\SQLEXPRESS；记下成功的写法和验证方式把可用的连接字符串写在草稿纸上
3WinForms 项目能否新建、编译、运行新建“Windows 窗体应用(.NET Framework)”，拖一个按钮，F5失败立即举手
4Chart 控件是否可用工具箱“数据”分组中找 Chart，拖到窗体上运行不可用时比赛中改用自绘图表
5Web API 2 项目能否新建并运行新建 ASP.NET Web 应用程序(.NET Framework) → Web API，F5NuGet 还原失败 → 比赛中直接用 HttpListener 方案
6HttpListener 控制台程序能否监听新建控制台应用，写 10 行启动 http://localhost:5000/，浏览器访问换端口再试
7Android 新项目能否同步并运行New Project → Empty Views Activity → Java，等 Gradle 同步，运行到模拟器同步失败立即举手——这是最致命的问题，必须在熟悉设备时发现
8模拟器Device Manager 中是否已有虚拟设备；启动耗时多久记下启动时间，比赛开始后第一件事就是启动模拟器
9adb reverse模拟器启动后执行 adb reverse tcp:5000 tcp:5000找不到 adb 时记下 SDK 路径
10模拟器访问接口模拟器浏览器访问 http://localhost:5000/不通时改用 10.0.2.2 方案并相应调整接口
11APK 打包Build → Build APK(s)记下 APK 输出路径
12Office / 模板Word 能否打开；有无产品操作手册模板没有 Office 时问清模块 C 的文档格式要求
13压缩工具右键文件夹 → 发送到 → 压缩(zipped)文件夹记下可用的压缩方式
14输入法、键盘中英文切换、常用符号赛场统一提供键盘鼠标，提前适应手感
15保存位置确认“指定盘符”和桌面路径记在草稿纸上
训练建议：熟悉设备也要演练

在最后一次全真模拟前，按这张清单在练习机上完整演练一次，计时 60 分钟。熟练的同学 30 分钟就能检查完，剩下的时间可以再跑一遍“新建项目 → 连数据库 → 打包”的完整流程。

03比赛流程与规则要点（辽宁文件）

环节规定
检录赛前 30 分钟凭参赛证和身份证检录；现场抽签确定工位
赛前准备每一模块赛前选手统一进场；赛前 10 分钟提供竞赛设备确认单
领取赛题赛前 5 分钟在发卷区统一领取赛题；裁判长宣布开始后才可以操作
比赛中数据文件必须存储在指定盘符并随时保存，数据丢失责任自负；有问题只能向裁判长反映；休息、饮水、去洗手间均计入比赛时间
设备故障由技术人员出具书面说明，抽签启用备用机位；非选手个人原因造成的故障可视情况延时，原则上不超过本模块竞赛时间的 20%；选手个人原因造成的不予延时
结束提示比赛结束前 15 分钟提示
提交结束铃声响起后立即停止工作；3 分钟内提交竞赛作品、图纸、U 盘、草稿纸等全部竞赛文件，并签名确认（文件另有“10 分钟内交至指定地点”的流程表述，以现场裁判要求为准）
提前结束需报裁判员批准，之后不得再进行任何比赛相关工作，原地等待至本场结束
禁带物品额外的软件、通讯设备（手机、智能手表、蓝牙耳机等）、U 盘等存储设备、照相录像设备、书籍和参考资料等；键盘鼠标由赛场统一提供
作品评判竞赛作品加密后交评分裁判组打分
易错提醒：作品中不要出现个人信息

作品是加密后评分的。不要在代码注释、窗体标题、文档封面、文件名中写自己的姓名、学校或其他可识别身份的信息（题目要求填写工位号等时按要求填写）。

04每个模块的开场 10 分钟

  1. 领到赛题后的 5 分钟（还不能操作）：快速通读一遍，在题目上圈出“必须”“至少”“不能”、数字和格式要求；记下交付文件夹和压缩包的准确名称。
  2. 开始后第 1 分钟：启动需要时间的东西——模拟器（模块 B）、SSMS、Visual Studio / Android Studio。
  3. 第 2–5 分钟：在桌面按题目要求建好交付文件夹（如 Modul1），在其中新建项目；导入题目给的数据库脚本，或建库。
  4. 第 5–10 分钟：在草稿纸上列出得分点清单（第 03 章的拆点法），按“分值大、依赖少”排出顺序，写上每个任务的计划完成时间（用第 12 章你的节奏表）。

05比赛中的时间控制

三条铁律（训练建议）

  1. 先完成，再完美：每个任务先把所有测量点做出“能用”的版本，再回头美化。测量分占绝大多数，而“做出来”是拿到它们的前提。
  2. 15 分钟卡住原则：一个问题卡住 15 分钟没有进展，立即跳过，做下一个；在草稿纸上记下来，最后有时间再回来。
  3. 每完成一个功能就保存和备份：Ctrl + Shift + S，每 30 分钟把交付文件夹复制一份到同一盘符的备份文件夹（备份文件夹不要放进交付文件夹里）。

时间检查点

以 2 小时模块为例（仅为参考，请用你自己模拟训练得出的节奏表）：

时间点应该完成落后时怎么办
0:10环境就绪、得分点清单—
0:40任务 1（10 分）全部测量点剩余的小点记下来，先开始任务 2
1:15任务 2 主体功能任务 2 中耗时的部分（如图表细节）后放
1:45任务 3 主体功能停止开发新功能，转入收尾
1:45–2:00收尾：自查 + 交付见下文

06最后 15 分钟：收尾流程

听到“还剩 15 分钟”的提示后，按以下顺序操作，不要再写新功能：

  1. 让程序能编译、能运行（3 分钟）：如果正在改的代码导致编译不过，立即注释掉或撤销。一个编译不过的项目，很可能所有功能都无法评分。
  2. 快速冒烟测试（4 分钟）：从启动开始，把主要功能点一遍。
  3. 更新交付物（3 分钟）：模块 B 重新 Build APK 并复制到交付文件夹；导出数据库脚本（如需要）；检查说明文件。
  4. 关闭开发工具（1 分钟）：关闭 Visual Studio / Android Studio，避免文件被占用导致压缩不完整。
  5. 压缩并检查（3 分钟）：按题目要求的准确名称压缩；打开压缩包确认内容完整（源码、APK、文档都在）；复制到 U 盘或指定位置。
  6. 留 1 分钟余量。
易错提醒：压缩包名称

辽宁样卷中模块 C 的文件夹叫 Modul3，压缩包却叫 Module3.zip。正式比赛时，严格照抄你拿到的赛题上的写法；拿不准就举手问。名称错误可能导致作品找不到或无法评分。

07常见突发情况

情况应对（建议）
电脑死机、蓝屏、软件无法启动立即举手报告裁判长，不要自己反复重启折腾；按规定由技术人员处理，必要时更换备用机位
Visual Studio 设计器打不开窗体（报错页）先“生成 → 重新生成解决方案”，再关闭设计器标签重新打开；仍不行，检查最近修改的 Designer.cs
Gradle 同步失败File → Sync Project with Gradle Files；检查是否误加了需要下载的依赖，删除后再同步
模拟器起不来或极慢Device Manager 中 Cold Boot；仍不行举手
数据库连接失败对照熟悉设备时记下的实例名；检查数据库名拼写；SSMS 中确认数据库存在
手机端所有请求失败按顺序查：接口是否运行 → 电脑浏览器能否访问 → adb reverse → INTERNET 权限 → 明文流量设置
题目有歧义先按最合理的理解做，并在说明文件中写明你的理解；涉及交付格式的问题举手问裁判长
心态崩了停下来深呼吸 30 秒，喝口水，看一眼得分点清单，挑一个最简单的点先做完。拿到一个点，状态就回来了

08模块之间与比赛结束后

  • 模块之间：不讨论上一个模块（无法改变了），吃点东西、活动一下，回顾下一个模块的开场 10 分钟流程。
  • 比赛结束后：按要求签字确认、清理工位、恢复设备原始状态，所有赛场物品不得带离。
  • 回去后：趁记忆清晰，把题目要点、自己的完成情况、遇到的问题写下来。无论结果如何，这份记录对下一次比赛（以及指导你的学弟学妹）都是最宝贵的材料。

09赛前最后检查清单

出发前
  • 参赛证、身份证
  • 已确认比赛地点、检录时间、交通路线
  • 没有携带任何禁带物品（手机等按赛场要求存放）
  • 前一晚睡眠充足
  • 早餐吃好，带水（以赛场规定为准）
  • 脑中过一遍：熟悉设备清单、开场 10 分钟、三条铁律、收尾流程
