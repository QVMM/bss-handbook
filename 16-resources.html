08怎样用官方文档

  1. 先查 API 页：遇到一个类（如 DataGridView），搜索“类名 + learn.microsoft.com”，看“属性”“方法”“事件”三张表和页面底部的示例。
  2. 看示例再看说明：先把示例代码复制到练习项目中跑起来，再读文字解释。
  3. 注意版本：页面顶部的版本选择要选 .NET Framework 4.8（WinForms、Web API 2 部分），不要看成 .NET 8 的内容。
  4. 整理成自己的笔记：查过的内容用一两句话写进错题本或笔记，比赛时你只能依靠记忆。
