01一句话认识这个项目

辽宁文件对本项目的概括是：单人赛，选手使用大赛提供的开发平台和数据库工具，按要求完成软件功能开发、移动应用程序开发等任务，主要考核理解、分析、逻辑思维、系统设计和软件开发能力。翻译成大白话：

主办方给你一个“业务场景”（例如智慧康养平台），你要在几个小时里，独自做出这个平台的管理端桌面程序、给手机用的数据接口、面向客户的手机 App，并对一个现成的 App 做测试、写操作手册。

它不考理论笔试。辽宁文件明确写了“不单独进行理论知识竞赛，相关内容融入到实际操作竞赛中”。你懂多少，全看你做出来多少。

03样卷长什么样

辽宁样卷的主题是“智慧康养平台”。请打开 PDF 第 21 页之后的样卷部分对照阅读，这里只概括结构：

模块面向谁已公开的任务写“略”的任务交付
A平台管理者（桌面端，Windows 10 及以上）1.1 登录/注册（10 分）：管理者注册（用户名唯一、密码≥8 位含字母+数字、确认密码、11 位电话，格式校验与提示）；用户名+密码登录，“记住密码”；登录成功进入系统首页（用户管理界面）1.2（15 分）、1.3（15 分）源码放桌面 Modul1 文件夹，压缩为 Modul1.zip 提交至 U 盘
B客户（手机端）2.1 登录/注册（10 分）：手机号注册，模拟 6 位验证码（1 分钟有效、可重新获取）；“手机号+密码”与“手机号+验证码”两种登录可切换；验证码重置密码2.2（15 分）、2.3（15 分）源码与打包后的 APK 放 Modul2，压缩为 Modul2.zip
C测试人员3.1 编写并执行测试用例（10 分），表 1 规定 11 个功能模块各自的最少用例数（合计至少 54 个）；3.2 撰写产品操作手册（10 分），用“平台——产品操作手册模板.docx”，分四部分—成果放 Modul3，压缩为 Module3.zip

样卷模块 A、B 的“项目和任务描述”里还有一组通用要求，它们在正式赛题中大概率同样出现，而且每一条都可能对应评分细项：

  • 整个开发过程使用所提供的风格指引；
  • 所有要求的模块必须可用，并有应有的验证和错误提示；
  • 列表或表格中的数据不能完整显示时显示滚动条，否则隐藏；
  • 日期使用 ISO 格式 YYYY-MM-DD；
  • 线框图只是参考，不需要一模一样；
  • 所有可交付成果在规定时间内完整交付；
  • 需要加载图片但没有对应图片时，显示默认图片 default.jpg；
  • 源码放在指定文件夹，按指定文件名压缩提交。
易错提醒：文件夹名要“抄”题目，不要“改”题目

样卷里文件夹叫 Modul1、Modul2、Modul3（少一个 e），而模块 C 的压缩包名写的是 Module3.zip。正式比赛时，请严格按你拿到的那份赛题的写法命名，哪怕你觉得它“拼错了”。如果拿不准，举手向裁判长确认。

04正式赛题和样卷是什么关系

文件依据辽宁文件 二、（四）公布方式

正式试题及评分表赛前保密，竞赛时发放。正式竞赛试题由裁判长对样题内容进行 30% 以内的修改。样题所包含的竞赛要素与正式赛题基本相同，但要素的数量可能不同。

这句话对备赛极其重要，它意味着：

  1. 样卷的主题、模块结构、题型，就是正式比赛的骨架。样卷练得越熟，正式比赛越有底。
  2. 但不要背答案。30% 以内的修改足以换掉几个界面、改几个字段、加几条校验规则。你要练到的是“看到类似需求就能快速做出来”，而不是“记住样卷的代码”。
  3. “要素数量可能不同”——例如样卷要求 54 个测试用例，正式题可能要求更多；样卷有 3 个子任务，正式题可能有 4 个。所以速度永远要留余量。

其他省份的文件可能有不同表述，以你所在赛区的文件为准。

05分数是怎么给的：测量分与评价分

辽宁文件写明“本次评分规则参照世界技能大赛评分规则执行”，评分分为两类：

测量分（Measurement）——客观的、可核对的

凡是能用客观数据描述的评判都叫测量。由 2 名及以上裁判组成一组，商量一致后只给一个分。文件给了两种类型的例子：

类型例子（概括）怎么给分
满分或零分个人中心页面点击“退出登录”可返回登录页，0.5 分做到给 0.5，做不到给 0
从满分中扣除页面具有文本框、提示框、按钮元素，2 分，每缺一种扣 0.5按缺项扣分

世赛 2026 技术描述里还有第三种：“从零分往上加”（例如每满足一条标准加 0.1 分），并要求打分时优先认可选手的成绩而不是惩罚遗漏。省赛多数评分表的实际形态，正如湖北样题评分表那样：一个界面拆成十几个 0.1–0.5 分的小项，每个小项“做到就给”。

评价分（Judgement）——主观的，按档给分

至少 2 名裁判各自独立打分，取平均；裁判之间分差必须 ≤1 分。每个模块先评评价分，再评测量分。档位：

分含义
0作品低于行业标准
1作品符合行业标准
2符合行业标准，且在某些方面高于行业标准
3全方位超过行业标准，接近完美

辽宁模块 A、B 各有 3 分评价分，模块 C 没有评价分。评价分通常看的是“整体观感”：界面是否统一、是否遵循风格指引、操作是否顺手、代码和命名是否规范。它总共只有 6 分，但在前几名分差很小时往往决定名次。

并列怎么排名

辽宁文件规定：总成绩并列时依次比较模块 B、模块 A、模块 C 的分数。也就是说，手机端成绩是第一决胜项。这再次说明模块 B 不能因为接口没做好而“整块塌掉”。

06用评分表的眼光看作品

辽宁的正式评分表不公开，但湖北样题配套的评分表（资料包 02-省级选拔赛样题/第46届世赛湖北省选拔赛-商务软件解决方案评分标准.xlsx）能让你清楚地看到裁判是怎样拆分数的。以它的“创建登录”子模块为例（总 4.9 分），评分细项大致是：

  • 界面元素是否齐全且正确：标题与输入提示、邮箱框、密码框、密码是否密文显示、角色选择、默认选“员工”、自动登录选项、默认勾选状态、登录按钮、关闭按钮——每项 0.1 分；
  • 验证码功能：失败三次后出现、4 位字母数字组合、点击可刷新；
  • 登录功能：各项都正确才登录成功、按角色跳转不同主界面；
  • 自动登录：7 天内再次运行能自动登录。

打开这份 xlsx，看一看“子评分表”工作表，你会注意到几个规律：

  1. “界面元素完整”几乎每个界面都有，而且很好拿。标题、按钮、输入框齐不齐，一眼可见。哪怕功能没写完，先把界面元素摆全，就能拿到这部分。
  2. “数据显示正确”分值最大。例如“查询航班”中，去程、返程航班的各个字段显示正确就各占 3 分。数据必须真的从数据库里查出来、算对。
  3. “细节规则”零碎但累计可观。余票≤3 显示红色、按时间升序、分页每页 10 条、不足 10 条不显示空行、Cancel 按钮红色……每条 0.1–0.5 分，十几条加起来就是好几分。
  4. “数据库确实被修改”单独给分。例如取消航班要求“数据库数据修改（0.4）”。界面上显示变了但数据库没变，这分拿不到。

湖北评分表中模块 A 的 11 个子模块合计 65 分、模块 B 的 7 个子模块合计 35 分，全部是测量分。辽宁的结构不同（A、B 各 40 分、含 3 分评价分），但“细项拆分”的思路是一致的。

07有竞争力的作品是什么样

根据评分表的结构，我们可以把“能争奖”的作品具体化为下面这张自查表。第 12 章做样卷时，每次都用它给自己打分。

维度及格水平争奖水平
完成度部分界面能用，个别功能是空按钮题目要求的每个界面都能打开、能操作、数据正确，没有空壳按钮

08比赛当天会经历什么

以下流程概括自辽宁文件“比赛基本流程”和“选手工作内容及纪律”。具体时间以赛区通知为准。

阶段发生什么你要做什么

熟悉设备赛场提供不少于 1 小时熟悉场地和设备，期间禁止修改设备参数按第 13 章的“熟悉设备清单”逐项检查：各软件能否打开、SQL Server 能否连上、能否新建并编译 WinForms 与 Android 工程、模拟器能否启动

易错提醒：设备故障与延时

辽宁文件规定：设备故障不能使用时由技术人员出具书面说明，选手抽签启用备用机位；因选手个人原因造成的故障不予延时；非选手原因的故障由裁判组视情况延时，原则上最长不超过本模块竞赛时间的 20%。所以“随时保存”不是客套话：换机位时，你只能带走已经保存到指定位置的东西。

省赛选拔出的选手，可能继续参加全国选拔乃至世赛集训。资料包里的世赛 2026 技术描述（03-国际世赛资料/WSC2026-TD09-技术描述(英文).pdf）说明了更高层级比赛的样貌，概括如下，供你确定长期目标：

项目世赛 2026 技术描述的内容（概括）
名称Software Applications Development（第 09 项），单人赛，参赛年龄不超过当年 22 岁
能力标准权重工作组织与管理 5%；沟通与人际 5%；问题解决与创新 10%；软件方案分析与设计 15%；软件方案开发 50%；软件测试 15%

省赛选手的主线仍然是 C# + SQL Server + WinForms + Web API + Android + 测试。Python 和 Draw.io 等内容放在附录与第 09 章，作为冲击更高层级时的拓展。
