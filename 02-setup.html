训练建议：自己的电脑版本“就低不就高”

清单写的是“及以上”，赛场实际可能装更新的版本。练习时用清单的版本或稍新的版本即可。真正要避免的是：你在家用了某个新版本才有的功能，到赛场发现没有。湖北 2020 年样题的赛场还是 Visual Studio 2015、SQL Server 2014、Android Studio 2.2.3，可见各赛区差别很大，一定以你赛区的清单为准。

02安装前的准备

  1. Windows 用户名不要有中文和空格。Android SDK、Gradle 在含中文或空格的路径下容易出现莫名其妙的错误。如果你的用户名是中文，后面安装 Android SDK 时务必把 SDK 放到 D:\Android\Sdk 这类纯英文路径。
  2. 打开文件扩展名显示。资源管理器 → 查看 → 勾选“文件扩展名”。否则你分不清 default.jpg 和 default.jpg.png。
  3. 确认 CPU 虚拟化已开启。任务管理器 → 性能 → CPU，看“虚拟化：已启用”。没有启用要进 BIOS 打开（Intel 叫 VT-x，AMD 叫 SVM），否则 Android 模拟器无法运行。
  4. 准备至少 100 GB 空闲空间。Visual Studio 约 10–20 GB，SQL Server 数 GB，Android Studio 加 SDK 和一个模拟器镜像约 15–25 GB。
  5. 建好备赛文件夹（见本章第 7 节）。

03Visual Studio 2022

安装

到 Visual Studio 官网下载 Community（社区版，个人学习免费）安装程序，运行后会出现“工作负载”选择页。勾选：

工作负载 / 组件为什么需要
.NET 桌面开发WinForms 窗体应用（模块 A 主体）
ASP.NET 和 Web 开发ASP.NET Web API（.NET Framework）项目模板与 IIS Express
“单个组件”中搜索并确认勾选 .NET Framework 4.8 目标包（Targeting Pack）保证能建 .NET Framework 4.8 项目
（可选）数据存储和处理在 VS 里直接浏览 SQL Server；不装也行，用 SSMS 即可

界面语言可在“语言包”页勾选中文（简体）；如果你准备冲击世赛，建议同时装英文语言包，后期切换成英文界面练习（世赛只提供英文版软件）。

验证一：WinForms 能跑

  1. 启动 VS → 创建新项目 → 在搜索框输入“Windows 窗体”。
  2. 选择“Windows 窗体应用(.NET Framework)”，语言 C#。不要选没有“(.NET Framework)”字样的那个——那个是新版 .NET（.NET 6/8），和赛场要求的 .NET Framework 4.8 不是一回事。
  3. 项目名 HelloForms，位置 D:\备赛\练习\02-环境，框架选 .NET Framework 4.8。
  4. 从“工具箱”拖一个 Button 到窗体，双击它，在生成的方法里写：MessageBox.Show("环境正常");
  5. 按 F5 运行，点按钮弹出提示框，即验证通过。

验证二：Web API 项目能跑

  1. 创建新项目 → 搜索“ASP.NET Web 应用程序(.NET Framework)”，项目名 HelloApi，框架 .NET Framework 4.8。
  2. 在模板选择页选“Web API”，取消“HTTPS 配置”（练习阶段用 HTTP 更简单）。
  3. 按 F5，浏览器会打开一个 http://localhost:端口号/ 的页面。在地址栏把路径改成 /api/values，能看到返回的数据（模板自带的示例），即验证通过。
  4. 记下端口号——第 07 章要用。
易错提醒

如果创建 Web API 项目时一直卡在“正在还原 NuGet 包”，或者报找不到 System.Web.Http，说明这台电脑缺少模板需要的包，并且没联网。家里练习时可以联网解决；但这正是赛场的风险点——第 07 章会教你一种完全不依赖 NuGet 的接口写法作为保底。

04SQL Server 2022 与 SSMS

安装 SQL Server

从微软官网下载 SQL Server 2022 的 Developer 版（开发者版，免费，功能完整）或 Express 版（免费，体积小）。

  1. 运行安装程序，选择“自定义”安装（能看清每一步）。进入“SQL Server 安装中心” → “全新 SQL Server 独立安装”。
  2. 功能选择至少勾选“数据库引擎服务”。
  3. 实例配置：Developer 版建议用“默认实例”（实例名 MSSQLSERVER），连接时服务器名写 . 或 localhost；Express 版默认是命名实例 SQLEXPRESS，连接时写 .\SQLEXPRESS。把你的实例名写进错题本。
  4. 数据库引擎配置 → 身份验证模式：选“混合模式”，给 sa 设一个密码，并点“添加当前用户”成为管理员。这样 Windows 身份验证和 SQL 身份验证两种连接方式你都能练。
  5. 完成安装。

安装 SSMS

SSMS（SQL Server Management Studio）是管理数据库的图形工具，单独下载安装（赛场要求 20.2 及以上）。

验证：能连接、能查询

  1. 打开 SSMS，连接窗口中：服务器类型“数据库引擎”，服务器名称填 .（或 .\SQLEXPRESS），身份验证选“Windows 身份验证”。
  2. SSMS 20 的连接窗口默认“加密”为“强制”，本机练习时请勾选“信任服务器证书”，否则可能报证书链不受信任的错误。
  3. 连接后点“新建查询”，输入 SELECT @@VERSION;，按 F5 执行，下方显示版本信息即通过。
  4. 再用 SQL Server 身份验证（用户名 sa 和你设的密码）连接一次，确认混合模式生效。
说明：关于 MySQL

辽宁文件文字中写了“MySQL 或 SQL Server”。但在 .NET Framework 中连接 SQL Server 用的是系统自带的 System.Data.SqlClient，不需要额外下载任何东西；连接 MySQL 则需要额外的连接器库。在赛场设备清单只列出 SQL Server 的情况下，SQL Server 是更稳的选择。如果你的赛区清单列了 MySQL，请在熟悉设备时确认 MySQL 连接器是否已经安装好。

05Android Studio

安装

  1. 从 Android 开发者官网下载 Android Studio（赛场要求 2023.2.1 及以上，即 Iguana 或更新）。安装时勾选 Android Virtual Device。
  2. 首次启动会进入安装向导，选择 Custom（自定义），把 SDK 路径改到 D:\Android\Sdk（纯英文、无空格）。
  3. 向导会联网下载 SDK 组件，耐心等待完成。

检查 SDK 组件

Tools → SDK Manager：

  • SDK Platforms：至少勾选一个较新的 Android 版本（例如 Android 14，API 34）。
  • SDK Tools：确认已装 Android SDK Build-Tools、Android Emulator、Android SDK Platform-Tools；在 Windows 上还需要硬件加速组件（新版本中通常是 Android Emulator hypervisor driver，或使用 Windows 自带的 Windows 虚拟机监控程序平台）。

创建模拟器

Tools → Device Manager → 创建设备：选一个常见手机型号（如 Pixel 系列），系统镜像选与上面相同 API 级别的 x86_64 镜像，完成后点运行，能看到手机桌面即可。

验证：Java 工程能跑

  1. New Project → 选择 Empty Views Activity（注意不是 Empty Activity——后者是 Compose 模板，只能用 Kotlin）。
  2. Name 填 HelloAndroid，Language 选 Java，Minimum SDK 选 API 24 左右，Build configuration language 用默认即可。
  3. 第一次创建会进行 Gradle 同步并下载依赖，可能需要十几分钟。右下角进度条走完、没有红色错误为止。
  4. 选中模拟器，点绿色三角运行，模拟器中出现“Hello World!”即通过。
  5. Build → Build App Bundle(s) / APK(s) → Build APK(s)，完成后点“locate”，能找到 app-debug.apk。记住这个路径：工程目录\app\build\outputs\apk\debug\。模块 B 要求提交 APK。
易错提醒：电脑卡死

Android Studio + 模拟器 + Visual Studio + SQL Server 同时开，16 GB 内存会比较吃紧，8 GB 内存会非常卡。练习时如果卡顿，可以：把模拟器的内存设为 2 GB；关闭不需要的浏览器标签；用真机调试（打开手机“开发者选项 → USB 调试”）。

06其他小工具（练习用）

  • curl.exe：Windows 10 1803 以后自带，在命令提示符里输入 curl --version 能看到版本。用它测试接口，不需要额外装软件。
  • 浏览器：直接访问 GET 接口看返回的 JSON。
  • 压缩：右键文件夹 → 发送到 → 压缩(zipped)文件夹，Windows 自带，赛场一般可用。练习时就用它，避免依赖某个压缩软件。
  • 文档编辑：模块 C 需要编辑 docx。家里用 Office 或 WPS 都可以练，但要熟练截图（Win+Shift+S）、插入图片、插入表格、生成目录。
  • Draw.io 桌面版（可选）：画 ER 图、用例图。世赛技术描述列出了它的离线版。

08离线演练：断网也要能开发

赛场电脑不连外网是常态（湖北样题明确写了“选手电脑不连接 Internet”，并且“不提供原介质包以外的第三方插件与代码库”）。辽宁文件没有专门写联网规则，但禁止自带额外软件，你也不应指望比赛时能下载任何东西。下面的演练请在环境装好后做一次，在第 11 章计划的“阶段检查周”再各做一次。

演练步骤

  1. 断网：拔网线或关闭 Wi-Fi（开启飞行模式）。
  2. VS：新建一个“Windows 窗体应用(.NET Framework)”，拖控件、写代码、连接本机 SQL Server 查一张表，运行。预期：全部正常——WinForms、ADO.NET（System.Data.SqlClient）、图表控件（System.Windows.Forms.DataVisualization）都属于 .NET Framework 自带，不需要下载。
  3. VS：新建一个 Web API（.NET Framework）项目并运行。观察是否能成功还原包、编译和运行。记录结果：成功，说明你这台电脑有本地包缓存；失败，说明赛场如果同样没有缓存，你需要用第 07 章的“零依赖接口”写法。
  4. Android Studio：打开之前已经成功编译过的 HelloAndroid，点 Build → Rebuild Project。预期：已下载过的依赖都在本机缓存中，可以编译成功。
  5. Android Studio：再新建一个 Empty Views Activity 工程（与之前相同的设置）。观察是否能同步成功。如果失败并提示无法下载某个依赖，说明新工程用到的版本不在缓存里。可以尝试在 Gradle 工具窗口启用离线模式（Offline Mode）后重新同步。
  6. 把演练结果记到错题本“环境”一页：哪些能离线、哪些不能、遇到了什么报错。
训练建议：赛场熟悉设备的一小时怎么用

赛场的开发环境由主办方准备，依赖缓存的情况你无法提前知道。所以熟悉设备时间（辽宁文件规定不少于 1 小时）最重要的事，就是在赛场那台电脑上把上面的演练快速做一遍：WinForms 能否运行、能否连上 SQL Server（实例名是什么）、Web API 模板能否创建运行、Android 新工程能否同步编译、模拟器能否启动、APK 能否生成。发现问题立即举手报告。完整清单见第 13 章。注意：熟悉设备期间禁止修改竞赛设备参数。

易错提醒：Android 依赖与 Gradle 缓存

Android 工程的界面库（如 androidx.appcompat、com.google.android.material、androidx.constraintlayout）并不是安装 Android Studio 就自带的，它们在第一次同步工程时从网络下载，之后存放在用户目录下的 .gradle 缓存里。家里断网能编译，是因为你之前联网下载过。这也是为什么本手册第 08 章坚持只用系统自带的类做网络请求和 JSON 解析——少一个依赖，就少一个赛场风险。
