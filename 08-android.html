01开始之前

官方文件怎么说

辽宁样卷模块 B：“本模块数据来源 Modul1 接口”；2.1 要求手机号注册（模拟发送 6 位验证码，1 分钟有效）、两种登录方式、重置密码；成果为 Modul2 文件夹，压缩为 Modul2.zip，需包含 APK。能力目录中还列有设备性能参数、可视化统计、传感器等内容。设备清单为 Android Studio 2023.2.1 及以上。

辽宁文件没有限定 Android 的开发语言。本手册用 Java：语法和 C# 非常接近，你在第 04 章学的几乎可以直接迁移；Android 官方文档也同时提供 Java 示例。已经会 Kotlin 的同学可以用 Kotlin，思路完全相同。

模板代码的两处调整

  • EdgeToEdge 代码：较新版本的模板会在 MainActivity.onCreate 中生成 EdgeToEdge.enable(this); 和一段 ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), …)。它引用了布局根节点的 android:id="@+id/main"。我们会替换布局，所以把这两段删掉，否则会因找不到 R.id.main 而编译失败或闪退。
  • 标题栏：较新模板的主题通常以 NoActionBar 结尾，页面顶部没有标题栏，代码中的 setTitle() 就看不到效果。需要标题栏时，打开 res/values/themes.xml，把 parent 改为 Theme.MaterialComponents.Light.DarkActionBar（Material 组件库是模板自带的依赖）。
关于本章的主题文件

本章附带的 themes.xml 中的 Theme.SmartCare 继承的是系统主题，仅为了让示例独立成立；你在 Android Studio 中建的项目保留模板生成的主题、只按上一条调整 parent 即可。HomeButton 样式可以直接复制到你的 themes.xml 中。

易错提醒：清单中的两个必加项

① 没有 INTERNET 权限，所有网络请求都会失败；② 没有 usesCleartextTraffic="true"，在 Android 9 及以上访问 http:// 地址会被系统拦截，报 “Cleartext HTTP traffic not permitted”。比赛中这两行最好在建项目后第一时间加上。

05工具类：校验、本地存储、验证码

先把几个各页面都要用的功能写成工具类，后面的页面代码会短很多。

格式校验

Check.java
package com.example.smartcare;

/** 输入格式校验，规则与桌面端保持一致 */
public class Check {
    public static boolean phone(String s) {
        return s != null && s.matches("^1\\d{10}$");
    }

    public static boolean password(String s) {
        return s != null && s.matches("^(?=.*[A-Za-z])(?=.*\\d).{8,}$");
    }

    public static boolean code(String s) {
        return s != null && s.matches("^\\d{6}$");
    }
}

Java 字符串中的反斜杠要写两个：正则 \d 在 Java 中写作 "\\d"。手机号这里要求“1 开头的 11 位数字”，比单纯“11 位数字”更严格；比赛中以题目描述为准。

本地存储 SharedPreferences

SharedPreferences 是 Android 的“键值对小本子”，适合保存登录状态、记住的账号密码、设置项。

Prefs.java
package com.example.smartcare;

import android.content.Context;
import android.content.SharedPreferences;

import org.json.JSONObject;

/** 用 SharedPreferences 保存登录状态和“记住密码”。数据存在 App 私有目录，卸载即清除。 */
public class Prefs {
    private static final String NAME = "smartcare";

    private static SharedPreferences sp(Context c) {
        return c.getSharedPreferences(NAME, Context.MODE_PRIVATE);
    }

    /** 登录成功后保存当前客户 */
    public static void saveLogin(Context c, JSONObject customer) {
        sp(c).edit()
                .putInt("customerId", customer.optInt("customerId"))
                .putString("phone", customer.optString("phone"))
                .putString("realName", customer.isNull("realName") ? "" : customer.optString("realName"))
                .apply();
    }

    public static int customerId(Context c) { return sp(c).getInt("customerId", 0); }

    public static String realName(Context c) { return sp(c).getString("realName", ""); }

    public static String phone(Context c) { return sp(c).getString("phone", ""); }

    public static void logout(Context c) {
        sp(c).edit().remove("customerId").remove("phone").remove("realName").apply();
    }

    public static void saveRemember(Context c, boolean remember, String phone, String pwd) {
        sp(c).edit()
                .putBoolean("remember", remember)
                .putString("savedPhone", remember ? phone : "")
                .putString("savedPwd", remember ? pwd : "")
                .apply();
    }

    public static boolean remember(Context c) { return sp(c).getBoolean("remember", false); }

    public static String savedPhone(Context c) { return sp(c).getString("savedPhone", ""); }

    public static String savedPwd(Context c) { return sp(c).getString("savedPwd", ""); }
}

模拟验证码

比赛环境没有短信网关，题目要求“模拟发送”。我们用对话框模拟一条短信，同时让“获取验证码”按钮进入 60 秒倒计时；校验时依次检查：是否已获取、手机号是否改变、是否过期、是否一致。

CodeHelper.java
package com.example.smartcare;

import android.app.AlertDialog;
import android.content.Context;
import android.os.CountDownTimer;
import android.widget.Button;

import java.util.Random;

/**
 * 模拟短信验证码：随机 6 位数字，1 分钟内有效。
 * 比赛环境没有短信网关，题目要求“模拟发送”，这里用对话框模拟短信。
 */
public class CodeHelper {
    private static final long VALID_MS = 60 * 1000;
    private String code;
    private String phone;
    private long expireAt;
    private CountDownTimer timer;

    /** 生成验证码、弹出“模拟短信”，并让按钮进入 60 秒倒计时 */
    public void send(Context ctx, String phone, final Button btn) {
        this.phone = phone;
        this.code = String.format("%06d", new Random().nextInt(1000000));   // 000000–999999，保证 6 位
        this.expireAt = System.currentTimeMillis() + VALID_MS;

        new AlertDialog.Builder(ctx)
                .setTitle("【模拟短信】")
                .setMessage("您的验证码是 " + code + "，1 分钟内有效。")
                .setPositiveButton("知道了", null)
                .show();

        btn.setEnabled(false);
        if (timer != null) timer.cancel();
        timer = new CountDownTimer(VALID_MS, 1000) {
            @Override
            public void onTick(long left) {
                btn.setText((left / 1000) + " 秒后重发");
            }

            @Override
            public void onFinish() {
                btn.setText("获取验证码");
                btn.setEnabled(true);
            }
        }.start();
    }

    /** 校验通过返回 null，否则返回错误提示 */
    public String check(String phone, String input) {
        if (code == null) return "请先获取验证码";
        if (!phone.equals(this.phone)) return "手机号已改变，请重新获取验证码";
        if (System.currentTimeMillis() > expireAt) return "验证码已过期，请重新获取";
        if (!code.equals(input)) return "验证码错误";
        code = null;   // 用过一次即作废
        return null;
    }

    /** 页面销毁时调用，避免倒计时继续操作已销毁的按钮 */
    public void cancel() {
        if (timer != null) timer.cancel();
    }
}
  • String.format("%06d", …) 保证不足 6 位时前面补 0（例如 4321 显示为 004321）。
  • “1 分钟有效”用过期时间戳判断，而不是依赖倒计时，这样即使页面切到后台再回来，判断仍然准确。
  • 验证码校验通过后立即作废，防止重复使用。

06访问接口：ApiClient

Android 有一条硬性规定：主线程（界面线程）不能做网络请求，否则直接抛出 NetworkOnMainThreadException；反过来，后台线程不能修改界面。所以每次请求都是：开一个后台线程发请求 → 拿到结果 → 切回主线程更新界面。下面的工具类把这个过程封装好，页面中只需要写“拿到结果后做什么”。

ApiClient.java
package com.example.smartcare;

import android.os.Handler;
import android.os.Looper;

import org.json.JSONObject;

import java.io.ByteArrayOutputStream;
import java.io.InputStream;
import java.io.OutputStream;
import java.net.HttpURLConnection;
import java.net.URL;
import java.net.URLEncoder;

/**
 * 访问 Web API 的工具类。
 * 网络请求不能放在主线程（会抛 NetworkOnMainThreadException），
 * 所以在后台线程请求，拿到结果后切回主线程回调，回调里可以直接操作界面。
 */
public class ApiClient {

    // 配合 adb reverse tcp:5000 tcp:5000 使用；不做映射时改为 http://10.0.2.2:5000
    public static final String BASE_URL = "http://localhost:5000";

    public interface Callback {
        void onResult(JSONObject result);   // result 一定不为 null，先看 result.optBoolean("success")
    }

    private static final Handler MAIN = new Handler(Looper.getMainLooper());

    public static void get(String path, Callback cb) {
        request("GET", path, null, cb);
    }

    public static void post(String path, JSONObject body, Callback cb) {
        request("POST", path, body, cb);
    }

    /** 查询参数中有中文或特殊字符时必须编码，例如 "/api/services?keyword=" + ApiClient.enc("助浴") */
    public static String enc(String s) {
        try {
            return URLEncoder.encode(s, "UTF-8");
        } catch (Exception e) {
            return s;
        }
    }

    private static void request(final String method, final String path, final JSONObject body, final Callback cb) {
        new Thread(() -> {
            JSONObject result;
            HttpURLConnection conn = null;
            try {
                conn = (HttpURLConnection) new URL(BASE_URL + path).openConnection();
                conn.setRequestMethod(method);
                conn.setConnectTimeout(5000);
                conn.setReadTimeout(8000);
                if (body != null) {
                    conn.setDoOutput(true);
                    conn.setRequestProperty("Content-Type", "application/json; charset=utf-8");
                    OutputStream os = conn.getOutputStream();
                    os.write(body.toString().getBytes("UTF-8"));
                    os.close();
                }
                int code = conn.getResponseCode();
                InputStream is = code < 400 ? conn.getInputStream() : conn.getErrorStream();
                String text = is == null ? "" : readAll(is);
                result = text.isEmpty() ? fail("服务器没有返回数据（状态码 " + code + "）") : new JSONObject(text);
            } catch (Exception e) {
                result = fail("网络连接失败，请确认接口已启动：" + e.getMessage());
            } finally {
                if (conn != null) conn.disconnect();
            }
            final JSONObject r = result;
            MAIN.post(() -> cb.onResult(r));
        }).start();
    }

    private static String readAll(InputStream is) throws Exception {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        byte[] buf = new byte[4096];
        int n;
        while ((n = is.read(buf)) != -1) bos.write(buf, 0, n);
        is.close();
        return bos.toString("UTF-8");
    }

    private static JSONObject fail(String msg) {
        JSONObject o = new JSONObject();
        try {
            o.put("success", false);
            o.put("message", msg);
        } catch (Exception ignored) {
        }
        return o;
    }
}

        // 校验顺序：从上到下，第一个错误就停下并定位到对应输入框

    }

import android.view.View;
import android.view.ViewGroup;

import android.widget.ImageView;

import org.json.JSONObject;

import java.util.ArrayList;
import java.util.List;

/** 服务列表适配器：把 JSONObject 列表“翻译”成一行一行的界面 */
public class ServiceAdapter extends BaseAdapter {
    private final Context ctx;
    private final List<JSONObject> data = new ArrayList<>();

    public ServiceAdapter(Context ctx) {
        this.ctx = ctx;
    }

    public void setData(List<JSONObject> list) {
        data.clear();
        data.addAll(list);
        notifyDataSetChanged();   // 通知 ListView 刷新
    }

    @Override public int getCount() { return data.size(); }

    @Override public JSONObject getItem(int position) { return data.get(position); }

    @Override public long getItemId(int position) { return getItem(position).optLong("serviceId"); }

    @Override
    public View getView(int position, View convertView, ViewGroup parent) {
        ViewHolder h;
        if (convertView == null) {          // 只有第一次才加载布局，滚动时复用旧的行，列表才流畅
            convertView = LayoutInflater.from(ctx).inflate(R.layout.item_service, parent, false);
            h = new ViewHolder();
            h.ivImage = convertView.findViewById(R.id.ivImage);
            h.tvName = convertView.findViewById(R.id.tvName);
            h.tvInfo = convertView.findViewById(R.id.tvInfo);
            h.tvPrice = convertView.findViewById(R.id.tvPrice);
            convertView.setTag(h);
        } else {
            h = (ViewHolder) convertView.getTag();
        }
        JSONObject s = getItem(position);
        h.tvName.setText(s.optString("serviceName"));
        h.tvInfo.setText(s.optString("categoryName") + " · " + s.optInt("durationMinutes") + " 分钟");
        h.tvPrice.setText(String.format("¥%.2f", s.optDouble("price")));
        ImageUtil.show(ctx, h.ivImage, s.isNull("imageName") ? null : s.optString("imageName"));
        return convertView;
    }

    static class ViewHolder {
        ImageView ivImage;
        TextView tvName, tvInfo, tvPrice;
    }
}

convertView 复用与 ViewHolder 是 ListView 的标准写法：列表有 100 行，屏幕上同时只显示 8 行，滚动时把移出屏幕的那一行“回收”拿来显示新数据，而不是每次都新建。数据多时，不这样写会明显卡顿。功能更复杂的列表可以用 RecyclerView，它强制采用这种复用方式，但需要 AndroidX 的 recyclerview 依赖。

package com.example.smartcare;

import android.content.Context;
import android.widget.ImageView;

/**
 * 按接口返回的图片文件名（如 "bath.jpg"）显示打包在 res/drawable 中的同名图片；
 * 文件名为空或找不到对应资源时显示默认图片 img_default。
 * 注意：资源名只能用小写字母、数字和下划线，并且不能叫 default（Java 关键字），
 * 所以题目给的 default.jpg 要改名为 img_default.jpg 再放进 drawable。
 */
public class ImageUtil {
    public static void show(Context ctx, ImageView iv, String fileName) {
        int id = 0;
        if (fileName != null && !fileName.isEmpty() && !"null".equals(fileName)) {
            String name = fileName.toLowerCase();
            int dot = name.lastIndexOf('.');
            if (dot > 0) name = name.substring(0, dot);          // 去掉扩展名
            name = name.replaceAll("[^a-z0-9_]", "_");            // 非法字符换成下划线
            id = ctx.getResources().getIdentifier(name, "drawable", ctx.getPackageName());
        }
        iv.setImageResource(id != 0 ? id : R.drawable.img_default);
    }
}

11可视化统计：自己画折线图

能力目录中有“可视化统计”。赛场如果不能下载第三方图表库，就只能自己画。自定义 View 的核心只有一个方法 onDraw(Canvas)：用 drawLine 画线、drawCircle 画点、drawText 写字。关键是把“数据值”换算成“屏幕坐标”：

y 坐标 = 底边 - (值 - 最小值) / (最大值 - 最小值) × 绘图区高度
x 坐标 = 左边 + 间距 × 序号

屏幕坐标的原点在左上角，y 向下增大，所以数值越大，y 越小，要用“底边减去”。

HealthChartView.java
package com.example.smartcare;

import android.content.Context;
import android.graphics.Canvas;
import android.graphics.Color;
import android.graphics.Paint;
import android.util.AttributeSet;
import android.view.View;

import java.util.ArrayList;
import java.util.List;

/**
 * 自绘折线图：不依赖任何第三方图表库。
 * 支持 1 条或 2 条折线（血压有收缩压、舒张压两条），超过警戒值的点画成红色。
 */
public class HealthChartView extends View {

    private final List<String> labels = new ArrayList<>();
    private final List<Float> values1 = new ArrayList<>();
    private final List<Float> values2 = new ArrayList<>();
    private String name1 = "", name2 = "";
    private float warn = Float.MAX_VALUE;     // 警戒值，超过显示红点

    private final Paint axis = new Paint(Paint.ANTI_ALIAS_FLAG);
    private final Paint line = new Paint(Paint.ANTI_ALIAS_FLAG);
    private final Paint text = new Paint(Paint.ANTI_ALIAS_FLAG);
    private final Paint dot = new Paint(Paint.ANTI_ALIAS_FLAG);

    public HealthChartView(Context context, AttributeSet attrs) {   // 在 XML 中使用必须有这个构造函数
        super(context, attrs);
        float dp = getResources().getDisplayMetrics().density;
        axis.setColor(Color.GRAY);
        axis.setStrokeWidth(1 * dp);
        line.setStrokeWidth(2 * dp);
        line.setStyle(Paint.Style.STROKE);
        text.setColor(Color.DKGRAY);
        text.setTextSize(11 * dp);
    }

    /** values2 可以传 null（只有一条线） */
    public void setData(List<String> labels, List<Float> values1, String name1,
                        List<Float> values2, String name2, float warn) {
        this.labels.clear(); this.labels.addAll(labels);
        this.values1.clear(); this.values1.addAll(values1);
        this.values2.clear(); if (values2 != null) this.values2.addAll(values2);
        this.name1 = name1; this.name2 = name2 == null ? "" : name2;
        this.warn = warn;
        invalidate();          // 请求重绘，系统随后会调用 onDraw
    }

    @Override
    protected void onDraw(Canvas canvas) {
        super.onDraw(canvas);
        float dp = getResources().getDisplayMetrics().density;
        float left = 40 * dp, right = getWidth() - 16 * dp, top = 30 * dp, bottom = getHeight() - 30 * dp;

        if (values1.isEmpty()) {
            canvas.drawText("暂无数据", getWidth() / 2f - 24 * dp, getHeight() / 2f, text);
            return;
        }
        // 1. 计算纵轴范围（上下各留 10% 空白）
        float max = -Float.MAX_VALUE, min = Float.MAX_VALUE;   // 注意不要用 Float.MIN_VALUE，它是最小的正数
        for (float v : values1) { max = Math.max(max, v); min = Math.min(min, v); }
        for (float v : values2) { max = Math.max(max, v); min = Math.min(min, v); }
        float pad = (max - min) * 0.1f + 1;
        max += pad; min -= pad;

        // 2. 坐标轴与纵轴刻度
        canvas.drawLine(left, top, left, bottom, axis);
        canvas.drawLine(left, bottom, right, bottom, axis);
        for (int i = 0; i <= 4; i++) {
            float v = min + (max - min) * i / 4;
            float y = bottom - (bottom - top) * i / 4;
            canvas.drawText(String.valueOf(Math.round(v)), 4 * dp, y + 4 * dp, text);
        }
        // 3. 横轴标签
        int n = values1.size();
        float step = n > 1 ? (right - left - 20 * dp) / (n - 1) : 0;
        for (int i = 0; i < n; i++) {
            float x = left + 10 * dp + step * i;
            canvas.drawText(labels.get(i), x - 14 * dp, bottom + 16 * dp, text);
        }
        // 4. 折线
        drawSeries(canvas, values1, Color.rgb(31, 78, 121), left, step, top, bottom, min, max, dp);
        if (!values2.isEmpty()) drawSeries(canvas, values2, Color.rgb(46, 160, 67), left, step, top, bottom, min, max, dp);
        // 5. 图例
        drawLegend(canvas, name1, Color.rgb(31, 78, 121), left, dp);
        if (!values2.isEmpty()) drawLegend(canvas, name2, Color.rgb(46, 160, 67), left + 90 * dp, dp);
        if (warn != Float.MAX_VALUE) drawLegend(canvas, "超出警戒", Color.RED, left + 180 * dp, dp);
    }

    private void drawSeries(Canvas c, List<Float> vs, int color, float left, float step,
                            float top, float bottom, float min, float max, float dp) {
        line.setColor(color);
        float px = 0, py = 0;
        for (int i = 0; i < vs.size(); i++) {
            float x = left + 10 * dp + step * i;
            float y = bottom - (vs.get(i) - min) / (max - min) * (bottom - top);
            if (i > 0) c.drawLine(px, py, x, y, line);
            dot.setColor(vs.get(i) >= warn ? Color.RED : color);
            c.drawCircle(x, y, 4 * dp, dot);
            c.drawText(trim(vs.get(i)), x - 10 * dp, y - 8 * dp, text);     // 在点上方显示数值
            px = x; py = y;
        }
    }

    private void drawLegend(Canvas c, String name, int color, float x, float dp) {
        dot.setColor(color);
        c.drawCircle(x + 5 * dp, 12 * dp, 5 * dp, dot);
        c.drawText(name, x + 14 * dp, 16 * dp, text);
    }

    private static String trim(float v) {        // 72.0 显示为 72，6.1 保持 6.1
        return v == Math.round(v) ? String.valueOf(Math.round(v)) : String.valueOf(v);
    }
}

        setTitle("健康数据");

        chart = findViewById(R.id.chart);
        tvSummary = findViewById(R.id.tvSummary);

    private static String typeOf(int checkedId) {
        if (checkedId == R.id.rbSugar) return "血糖";
        if (checkedId == R.id.rbHeart) return "心率";
        return "血压";
    }

    private void load(final String type) {
        ApiClient.get("/api/health?customerId=" + Prefs.customerId(this) + "&type=" + ApiClient.enc(type), result -> {
            List<String> labels = new ArrayList<>();
            List<Float> v1 = new ArrayList<>(), v2 = new ArrayList<>();
            JSONArray arr = result.optJSONArray("data");
            for (int i = 0; arr != null && i < arr.length(); i++) {
                JSONObject r = arr.optJSONObject(i);
                labels.add(r.optString("measuredAt").substring(5, 10));   // "2026-10-01 08:00:00" -> "10-01"
                v1.add((float) r.optDouble("value1"));
                if (!r.isNull("value2")) v2.add((float) r.optDouble("value2"));
            }
            // 警戒值为练习设定，比赛以题目为准
            if ("血压".equals(type)) chart.setData(labels, v1, "收缩压", v2, "舒张压", 140f);
            else if ("血糖".equals(type)) chart.setData(labels, v1, "血糖 mmol/L", null, null, 7.0f);
            else chart.setData(labels, v1, "心率 次/分", null, null, 100f);
            tvSummary.setText(summary(v1, "血压".equals(type) ? "收缩压" : type));
        });
    }

    private static String summary(List<Float> v, String type) {
        if (v.isEmpty()) return "暂无" + type + "记录";
        float max = v.get(0), min = v.get(0), sum = 0;
        for (float x : v) { max = Math.max(max, x); min = Math.min(min, x); sum += x; }
        return String.format(Locale.CHINA, "%s 共 %d 次　最高 %.1f　最低 %.1f　平均 %.1f　最近一次 %.1f",
                type, v.size(), max, min, sum / v.size(), v.get(v.size() - 1));
    }

package com.example.smartcare;

import android.app.AlertDialog;
import android.content.Context;
import android.content.Intent;
import android.hardware.Sensor;
import android.hardware.SensorEvent;
import android.hardware.SensorEventListener;
import android.hardware.SensorManager;
import android.net.Uri;
import android.os.Bundle;
import android.widget.ListView;
import android.widget.SimpleAdapter;
import android.widget.TextView;
import android.widget.Toast;

import androidx.appcompat.app.AppCompatActivity;

import org.json.JSONArray;
import org.json.JSONObject;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

/** 紧急求助：联系人列表、一键拨号、摇一摇求助（加速度传感器） */
public class SosActivity extends AppCompatActivity implements SensorEventListener {

    private static final float SHAKE_THRESHOLD = 15f;   // 练习阈值，静止时加速度约 9.8
    private SensorManager sensorManager;
    private Sensor accelerometer;
    private long lastShake;
    private boolean dialogShowing;
    private final List<Map<String, String>> contacts = new ArrayList<>();
    private SimpleAdapter adapter;
    private TextView tvSensor;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_sos);
        setTitle("紧急求助");

        tvSensor = findViewById(R.id.tvSensor);
        ListView lv = findViewById(R.id.lvContacts);
        lv.setEmptyView(findViewById(R.id.tvEmpty));
        // SimpleAdapter：用系统自带的两行布局显示“姓名（关系）”和电话
        adapter = new SimpleAdapter(this, contacts, android.R.layout.simple_list_item_2,
                new String[]{"title", "phone"}, new int[]{android.R.id.text1, android.R.id.text2});
        lv.setAdapter(adapter);
        lv.setOnItemClickListener((p, v, position, id) -> dial(contacts.get(position).get("phone")));

        findViewById(R.id.btnCallFirst).setOnClickListener(v -> {
            if (contacts.isEmpty()) Toast.makeText(this, "还没有紧急联系人", Toast.LENGTH_SHORT).show();
            else dial(contacts.get(0).get("phone"));
        });

        sensorManager = (SensorManager) getSystemService(Context.SENSOR_SERVICE);
        accelerometer = sensorManager == null ? null : sensorManager.getDefaultSensor(Sensor.TYPE_ACCELEROMETER);
        if (accelerometer == null) tvSensor.setText("本设备没有加速度传感器，摇一摇不可用");

        loadContacts();
    }

    private void loadContacts() {
        ApiClient.get("/api/contacts?customerId=" + Prefs.customerId(this), result -> {
            contacts.clear();
            JSONArray arr = result.optJSONArray("data");
            for (int i = 0; arr != null && i < arr.length(); i++) {
                JSONObject c = arr.optJSONObject(i);
                Map<String, String> m = new HashMap<>();
                m.put("title", c.optString("contactName") + "（" + c.optString("relation") + "）");
                m.put("phone", c.optString("phone"));
                contacts.add(m);
            }
            adapter.notifyDataSetChanged();
        });
    }

    /** 打开拨号界面并填好号码。ACTION_DIAL 不需要拨打电话权限，由用户自己按下拨打 */
    private void dial(String phone) {
        startActivity(new Intent(Intent.ACTION_DIAL, Uri.parse("tel:" + phone)));
    }

    // ---------- 传感器：页面可见时注册，离开时注销，否则会一直耗电 ----------
    @Override
    protected void onResume() {
        super.onResume();
        if (accelerometer != null) sensorManager.registerListener(this, accelerometer, SensorManager.SENSOR_DELAY_UI);
    }

    @Override
    protected void onPause() {
        super.onPause();
        if (accelerometer != null) sensorManager.unregisterListener(this);
    }

    @Override
    public void onSensorChanged(SensorEvent e) {
        float x = e.values[0], y = e.values[1], z = e.values[2];
        double g = Math.sqrt(x * x + y * y + z * z);
        tvSensor.setText(String.format("加速度 x=%.1f y=%.1f z=%.1f　合计 %.1f", x, y, z, g));
        long now = System.currentTimeMillis();
        if (g > SHAKE_THRESHOLD && now - lastShake > 2000 && !dialogShowing && !contacts.isEmpty()) {
            lastShake = now;                 // 2 秒内只触发一次，防止连续弹窗
            dialogShowing = true;
            new AlertDialog.Builder(this)
                    .setTitle("检测到摇一摇")
                    .setMessage("是否呼叫紧急联系人 " + contacts.get(0).get("title") + "？")
                    .setPositiveButton("呼叫", (d, w) -> dial(contacts.get(0).get("phone")))
                    .setNegativeButton("取消", null)
                    .setOnDismissListener(d -> dialogShowing = false)
                    .show();
        }
    }

    @Override
    public void onAccuracyChanged(Sensor sensor, int accuracy) { }
}

  • 在模拟器中测试：模拟器右侧工具栏 “⋯”（Extended controls）→ Virtual sensors，拖动手机模型或修改加速度数值。
  • ACTION_DIAL 只是打开拨号界面并填好号码，不需要申请拨打电话权限；如果题目要求“直接拨出”，需要 ACTION_CALL 和运行时申请 CALL_PHONE 权限，复杂得多，没有要求时不要自找麻烦。

            boolean charging = status == BatteryManager.BATTERY_STATUS_CHARGING || status == BatteryManager.BATTERY_STATUS_FULL;
            sb.append("电量：").append(level * 100 / scale).append("%　").append(charging ? "充电中" : "未充电").append('\n');

        SensorManager sm = (SensorManager) getSystemService(Context.SENSOR_SERVICE);
        if (sm != null) {
            sb.append("传感器：共 ").append(sm.getSensorList(Sensor.TYPE_ALL).size()).append(" 个\n");
            for (Sensor s : sm.getSensorList(Sensor.TYPE_ALL)) sb.append("　· ").append(s.getName()).append('\n');
        }
        tvInfo.setText(sb.toString());
    }

14打包 APK 与交付 Modul2

  1. 菜单 Build → Build App Bundle(s) / APK(s) → Build APK(s)。完成后右下角提示 “locate”，点击打开文件夹。
  2. 调试版 APK 位于 app\build\outputs\apk\debug\app-debug.apk。调试版已经自动签名，可以直接安装到模拟器或手机上。
  3. 验证：把 APK 拖到模拟器窗口即可安装。卸载旧版本后安装一次，从头走一遍主要功能。
  4. 按题目要求整理：样卷要求 Modul2 文件夹包含源码和 APK，压缩为 Modul2.zip。训练建议的结构如下（题目另有要求时以题目为准）：

├─ SmartCare\            ← Android 项目源码（可删除 app\build 和 .gradle 文件夹减小体积）
├─ SmartCare.apk         ← 从 app-debug.apk 复制并改名
