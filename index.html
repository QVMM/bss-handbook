人社口 · 世界技能大赛第 09 项 · 零基础备赛教程

商务软件解决方案
从零到能拿奖的备赛教程

这是一本写给“什么都还不会”的同学的训练手册。它不假设你学过编程，也不假设你身边有懂行的老师。你只要每天打开它，按顺序做完当天的练习，就能一步步走到：在规定时间里，独立完成一套桌面端 + 接口 + 手机端 + 测试文档的完整作品，并且让裁判在评分表上一项一项地给你打勾。

01这本手册是什么

“商务软件解决方案”是人社部门组织的职业技能大赛中的一个项目，对应世界技能大赛的第 09 项（英文旧称 IT Software Solutions for Business，2026 年第 48 届世赛的技术描述已改称 Software Applications Development，中文也常称“软件应用开发”）。省赛、国赛选拔通常都参照世赛的评分方式进行：大部分分数是“做到了就给分、没做到就不给”的客观测量分，少部分是裁判按 0–3 档给的主观评价分。

本手册围绕你手上已经有的资料包《商务软件解决方案-人社口备赛资料.zip》编写。其中最重要的一份文件是辽宁省 2026 年发布的技术工作文件（含样卷），它把比赛拆成三个模块：

模块 A · 40%软件功能开发（桌面端，Visual Studio / .NET + 数据库），2 小时
模块 B · 40%手机功能开发（Android），2 小时，数据来自模块 A 的接口
模块 C · 20%应用测试（编写并执行测试用例、撰写产品操作手册），2 小时
合计 6 小时比赛共 1.5 天；测量分 94 分 + 评价分 6 分

上面这些数字都来自资料包里的辽宁文件，第 01 章会逐条带你核对。不同省份、不同年份的赛制可能不同，你拿到自己赛区的技术文件后，要先按第 00 章的方法做一次“对表”。

02如果你现在很迷茫，请先做这三件事

  1. 今天：读完本页和第 00 章《如何使用本手册》（约 40 分钟），然后打开资料包里的 01-官方技术文件/2026-辽宁省第三届职业技能大赛-商务软件解决方案技术工作文件(含样卷).pdf，只看第 1–8 页，用笔圈出“模块、时长、分数”三样东西。
  2. 明天：按第 02 章准备电脑，至少装好 Visual Studio 2022 并运行出第一个“Hello”窗口。电脑装不好不要硬撑，第 02 章有逐项检查表。
  3. 第三天起：翻到第 11 章《训练计划》，选“标准版”或“强化版”，把每周的格子抄到你的本子或日历上，然后从第 03 章开始学。
教练的话

零基础的同学最常犯的错误，是一上来就打开 Android Studio 想做手机 App，结果被各种报错劝退。本手册的学习顺序是刻意安排的：先学会用 C# 思考和写程序，再学数据库，再做桌面程序，再把桌面端的数据“开放”成接口，最后才做手机端。这个顺序和比赛里模块 A → 模块 B 的依赖关系完全一致——模块 B 的数据就是从模块 A 的接口拿的。

03你需要准备什么

项目最低要求说明
电脑Windows 10 或 11，64 位；内存 16 GB；固态硬盘剩余 100 GB 以上辽宁文件给出的赛场电脑配置是 Intel i5 十代以上、16 GB 内存、256 GB 硬盘。Android 模拟器很吃内存，8 GB 内存的电脑能学，但会非常卡。
软件Visual Studio 2022、SQL Server 2022、SSMS 20.2 以上、Android Studio 2023.2.1 以上版本下限来自辽宁文件的基础设施清单。第 02 章有安装与验证步骤。
时间标准版每周 12–15 小时，约 8 个月；强化版每周 25–30 小时，约 5 个月见第 11 章。离比赛不足 5 个月也能用强化版，但要优先保住模块 A 和模块 B 的基础分。
文具一个专用笔记本、一个计时器（手机计时即可，模拟时手机放远）赛场不允许带资料，所以每天要把“容易忘的写法”抄进自己的“错题本”，赛前反复背。
资料包《商务软件解决方案-人社口备赛资料.zip》解压到一个固定位置建议放到 D:\备赛\资料包\，不要放在桌面或下载文件夹里，免得误删。

04每周要花多少时间

下面是两条默认路线。你的比赛日期请以自己省份的通知为准，第 11 章会教你从比赛日往回倒推，把训练计划“钉”在日历上。

路线总时长每周投入适合谁
标准版约 34 周（8 个月）12–15 小时：工作日每天 1.5 小时，周末每天 3 小时在校学生，平时要上课；第一次参赛
强化版约 21 周（5 个月）25–30 小时：每天 4 小时左右，周末整块模拟集训队员、已停课备赛的学生；或学过一点编程

无论哪条路线，最后 6–7 周都留给整套样卷的计时训练。很多同学不是不会，而是“会但做不完”——这个问题只能靠计时训练解决。

05手册的结构

第 00 章如何使用本手册学习方法、资料包怎么配合、怎样记训练日志。 第 01 章赛项全景比赛日流程、模块与分值、测量分和评价分、获奖作品长什么样。 第 02 章环境搭建与离线演练逐个安装并验证开发工具，练习断网编译。 第 03–10 章学习路径计算思维 → C# → SQL → WinForms → Web API → Android → UML → 测试。 第 11 章训练计划标准版与强化版逐周安排，每阶段都有过关标准。 第 12 章样卷精练辽宁、湖北样卷的计时做法、自评方法、补全“略”的部分。 第 13 章赛场战术两小时怎么分、先做什么、怎么保存和提交。 第 14 章常见错误大全连接字符串、端口、模拟器访问、编码、第三方包…… 第 15–17 章工具箱模板与自评表、学习资源、术语表，以及 Python 选修附录。

06阅读约定

为了让你分清“哪些是比赛规定、哪些是教练建议”，全书使用以下几种提示框：

文件依据来源：资料包中的某个具体文件

这里写的内容来自官方或赛区文件。我们只概括要点，不大段照抄；需要原文时，请打开括号里注明的文件。

训练建议

这是教练经验，不是比赛规定。按建议做通常更稳，但你可以根据自己的情况调整。

易错提醒

前人反复踩过的坑。看到这种框，最好把内容抄进错题本。

过关标准

达到这里描述的水平，再进入下一阶段。达不到就多练一周，不要硬往前赶。

说明

背景知识或补充解释。

练习题的“参考答案”或“预期结果”默认折叠，先自己做，做完再点开对照。打印本手册时，折叠内容会自动展开。

每章正文中的代码都可以照着敲。请一定自己敲，不要复制粘贴——赛场上没有地方可以复制，你的手指需要记住这些写法。
