常见错误大全

这一章收集了备赛过程中最常见、最浪费时间、最容易丢分的错误，按“现象 → 原因 → 解决”整理。遇到问题先来这里查；平时也建议每周翻一遍，把“别人踩过的坑”变成你的经验。把你自己遇到的新问题，按同样格式补进错题本。

01读题与交付类（丢分最多）

现象原因解决
功能都做了，分数却不高漏掉了题目“通用要求”中的条目：滚动条、YYYY-MM-DD 日期、default.jpg、风格指引、验证与错误提示把通用要求抄成一张清单贴在显示器边，每个界面做完对照一次
某个要求完全没做只读了一遍题，边做边看，漏掉了段落中间的一句第 03 章“读题三遍法”；开场就列出得分点清单，做完一条划一条
裁判打开压缩包找不到作品压缩包或文件夹名称与题目不一致（Modul / Module）；或压缩的是快捷方式严格照抄题目写法；压缩后打开检查一遍
压缩包里没有 APK只压缩了源码辽宁样卷要求 Modul2.zip 包含 APK；交付前对照题目逐项检查
裁判电脑上程序连不上数据库连接字符串写死了自己电脑的实例名；数据库没有导出脚本连接字符串放在配置文件中；说明文件写清数据库名和修改方法；按要求导出脚本
提交的是旧版本改完代码没有重新生成 / 重新 Build APK收尾流程第一步：重新生成并运行一次
作品无法编译最后几分钟改代码引入了错误最后 15 分钟不写新功能；编译不过立即撤销
作品中出现个人姓名、学校注释、窗体标题、文档封面中写了自己的信息作品加密评分，一律不写可识别身份的信息

02C# 语言

现象原因解决
5 / 2 结果是 2两个整数相除是整数除法至少一个写成小数：5 / 2.0，或 (decimal)a / b
输入为空时程序崩溃，提示“输入字符串的格式不正确”用了 int.Parse，空字符串无法转换一律用 int.TryParse，转换失败时提示用户
金额出现 0.30000000000000004 这类误差用 double 存金额金额一律用 decimal（数据库对应 DECIMAL）
Math.Round(2.5) 得到 2默认是“银行家舍入”（四舍六入五取偶）Math.Round(x, 2, MidpointRounding.AwayFromZero)
日期显示成 2026-30-05 或 02:30 变成 14:30 的错乱格式字符串大小写写错：MM 是月、mm 是分；HH 是 24 小时、hh 是 12 小时日期 yyyy-MM-dd，时间 HH:mm:ss
“未将对象引用设置到对象的实例”对 null 调用了方法，例如表格没有选中行时访问 dgv.CurrentRow.Cells使用前判断：if (dgv.CurrentRow == null) { 提示; return; }
“对象不能从 DBNull 转换为其他类型”数据库字段为 NULL 时直接 Convert.ToInt32 / 强制转换先判断 row["X"] == DBNull.Value；或在 SQL 中用 ISNULL
年龄算错一岁只用年份相减，没有考虑今年生日是否已过年份相减后，如果今天还没到今年的生日就再减 1（第 04 章练习 4-13）
正则 \d{11} 对 12 位数字也返回 true没有加开头 ^ 和结尾 $，只要“包含”就匹配校验整串一定写 ^...$
程序运行一段时间后数据库连接耗尽、变慢SqlConnection 没有关闭一律写在 using (...) { } 中

03SQL 与数据库

现象原因解决
表建好了却在自己的库里找不到执行脚本时当前数据库是 master，表建进了 master脚本开头写 USE 数据库名; GO；执行前看 SSMS 工具栏的数据库下拉框
中文存进去变成问号字段类型是 VARCHAR，或字符串常量没有加 N 前缀中文字段用 NVARCHAR；常量写 N'张三'；C# 中用参数传值则不需要考虑
同一个日期字符串，在不同电脑上插入结果不同或报错'2026-03-04' 转为 DATETIME 时受服务器语言设置影响（可能被理解为 4 月 3 日）脚本中写 '20260304' 或 '2026-03-04T08:00:00'；C# 中用参数传 DateTime
UPDATE 后全表数据都变了忘写 WHERE先写 WHERE 再写 SET；重要操作前先用 SELECT 加同样的 WHERE 看看会影响哪些行
WHERE Name = NULL 查不到任何数据NULL 不能用等号比较WHERE Name IS NULL
统计人数比实际少COUNT(列名) 不计 NULL统计行数用 COUNT(*)
“选择列表中的列无效，因为该列没有包含在聚合函数或 GROUP BY 子句中”SELECT 中有未分组也未聚合的列把该列加入 GROUP BY，或用聚合函数包起来
OFFSET 分页报语法错误OFFSET … FETCH 必须跟在 ORDER BY 后面分页查询一定有 ORDER BY
按日期范围查询，结束当天的数据查不到写了 <= '2026-10-31'，只包含 0 点那一刻写 < 结束日期 + 1 天
删除客户时报外键冲突该客户有订单引用业务上一般用“禁用”（软删除）代替删除；确需删除时先处理子表
新增后取到的编号不对用了 @@IDENTITY（可能取到触发器中插入的值）用 SCOPE_IDENTITY()，与 INSERT 写在同一条命令中
模糊查询结果不对或报错把 % 写进了 SQL 字符串里又加了引号，或拼接用户输入LIKE @kw，参数值为 "%" + 关键字 + "%"
SSMS 连接报证书错误新版 SSMS 默认加密连接连接对话框中勾选“信任服务器证书”（第 02 章）

04WinForms

现象原因解决
点击按钮没有任何反应事件方法是从别处复制来的，没有绑定到控件属性窗口 → 闪电图标 → 在对应事件右侧下拉选择该方法；或双击控件重新生成
删掉一个事件方法后，设计器打不开、编译报错Designer.cs 里仍有 this.btnX.Click += ... 这一行双击错误定位到该行删除；以后删除事件先在属性窗口的事件列表中清空
执行 SQL 报“参数化查询需要参数 @s，但未提供该参数”new SqlParameter("@s", 0) 中的 0 被当成了 SqlDbTypenew SqlParameter("@s", SqlDbType.Int) { Value = 0 }
表格最后总有一行空白AllowUserToAddRows 默认为 True设为 False；同时 ReadOnly = True、SelectionMode = FullRowSelect
列标题显示的是英文字段名DataTable 自动生成的列用字段名作标题SQL 中起中文别名，或设置 dgv.Columns["X"].HeaderText
替换照片时报“文件正由另一进程使用”用 Image.FromFile 加载后文件被锁定先读成字节再从内存流创建图片（第 06 章 ImageHelper）
图片在自己电脑上能显示，换电脑就没有写了绝对路径，或图片没有复制到输出目录路径用 Application.StartupPath 拼接；图片文件属性“复制到输出目录”设为“如果较新则复制”
登录后关闭首页，程序还在后台运行登录窗只是隐藏了，没有关闭首页 FormClosed 时根据情况关闭登录窗或 Application.Exit()
登录成功后程序直接退出关闭了作为主窗体的登录窗登录窗 Hide() 而不是 Close()（第 06 章）
编辑窗口关闭后列表没刷新用 Show 打开，或没有判断 DialogResultif (f.ShowDialog() == DialogResult.OK) LoadData();
“记住密码”重启后没有效果修改设置后没有调用 Properties.Settings.Default.Save()；或设置的范围选了“应用程序”（只读）范围选“用户”，修改后调用 Save()
ConfigurationManager 下有红色波浪线没有添加 System.Configuration 引用引用 → 添加引用 → 程序集 → System.Configuration
下拉框一加载就触发查询，甚至报错绑定数据源时会触发 SelectedIndexChanged加载期间用一个标志变量跳过事件（第 06 章 _loading）
窗体放大后控件挤在左上角没有设置 Anchor / Dock表格 Anchor 设为上下左右；或者固定窗体大小
界面上到处是 Form1、button1、textBox1没有命名放一个控件就改一个 Name 和 Text（第 04 章命名规范）

05Web API 接口

现象原因解决
HttpListener 启动报“拒绝访问”地址写成了 http://+:端口/ 或 http://*:端口/，需要管理员权限改为 http://localhost:端口/
启动报端口被占用上一次的接口程序还没关，或其他程序占用关闭旧的控制台窗口；或换一个端口（手机端同步修改）
日期返回成 /Date(1727740800000)/JavaScriptSerializer 直接序列化 DateTime转换成字符串再输出（第 07 章 Json.Rows）
手机端取不到字段值，值总是空字段名大小写不一致（接口返回 ServiceName，手机端取 serviceName）接口统一小驼峰，并写进接口文档；两端照文档写
中文变成乱码没有用 UTF-8 读写请求体或响应读请求用 new StreamReader(stream, Encoding.UTF8)，响应 Content-Type 带 charset=utf-8
POST 时接口收到的数据全是空请求头没有 Content-Type: application/json；或 JSON 键名写错curl 测试时加 -H "Content-Type: application/json"；对照接口文档
IIS Express 返回 “Bad Request - Invalid Hostname”模拟器用 10.0.2.2 访问，IIS Express 只接受 localhost使用 adb reverse，手机端用 localhost（第 07 章）
接口抛异常后整个服务停止没有捕获异常在请求处理的最外层 try-catch，返回 500 和错误信息（第 07 章 ApiServer.Start）

06Android

现象（Logcat 中的关键字）原因解决
NetworkOnMainThreadException在主线程发网络请求在后台线程请求（第 08 章 ApiClient）
CalledFromWrongThreadException：Only the original thread that created a view hierarchy can touch its views在后台线程修改了界面回到主线程再更新界面（Handler 或 runOnUiThread）
Cleartext HTTP traffic to localhost not permittedAndroid 9 起默认禁止 http 明文请求清单 application 节点加 android:usesCleartextTraffic="true"
SecurityException: Permission denied (missing INTERNET permission?)没有声明网络权限清单加 <uses-permission android:name="android.permission.INTERNET" />
ConnectException: Failed to connect to localhost模拟器中的 localhost 是模拟器自己；没有做端口映射；接口没启动执行 adb reverse；或改用 10.0.2.2；确认接口在运行
ActivityNotFoundException新页面没有在清单中注册用 New → Activity 创建（自动注册），或手动加 <activity android:name=".XxxActivity" />
打开页面就闪退，NullPointerException 指向 findViewById 之后的行id 写错，或 setContentView 用了别的布局检查布局文件名与 id；setContentView 必须在 findViewById 之前
新建项目后编译报找不到 R.id.main替换了布局，但模板中的 EdgeToEdge 代码还在引用它删除模板生成的 EdgeToEdge 和 setOnApplyWindowInsetsListener 代码（第 08 章）
字符串判断永远不相等Java 中用 == 比较字符串（比较的是引用）用 a.equals(b)；C# 转过来的同学特别注意
资源编译报错：文件名叫 default 时提示 invalid symbol name '…drawable/default'；含横线或大写字母时提示 is not a valid file-based resource name characterdrawable 文件名含大写、横线、以数字开头或是 Java 关键字改为小写字母、数字、下划线，如 img_default.jpg
界面上显示文字 “null”optString 取到 JSON 中的 null 值会返回字符串 "null"先 isNull("key") 判断
选的是 3 月，显示成 2 月Calendar / DatePicker 的月份从 0 开始显示时加 1，设置时减 1
列表数据变了，界面没变修改数据后没有通知适配器adapter.notifyDataSetChanged()
离开页面后手机仍在耗电，或摇一摇在其他页面也触发传感器监听没有注销onResume 注册、onPause 注销
Gradle 同步卡住或失败添加了需要联网下载的依赖库，赛场断网只用模板自带的依赖；本手册的代码不需要任何额外依赖
倒计时结束前离开页面后闪退CountDownTimer 仍在更新已销毁的按钮onDestroy 中 cancel（第 08 章 CodeHelper.cancel）
连点登录按钮，提交了好几次请求期间按钮仍可点击请求开始时 setEnabled(false)，结束后恢复

07测试与文档（模块 C）

现象原因解决
预期结果写“正常”“成功”预期不具体，无法判断写出具体的提示文字、跳转页面、数据变化
一条用例里测了好几件事为了省事合并一条用例只验证一个点
某个功能模块的用例数不够前面的模块写太多，后面没时间先按模块搭框架，每个模块先写够数量（第 10 章）
测试结果全是“通过”没有真实执行逐条在模拟器上操作后再填
步骤写“输入错误的密码”不具体，别人无法复现写出实际输入的值
操作手册只有文字没有截图执行用例时顺手截图并按功能命名
手册目录页码不对手工输入目录用标题样式 + 自动目录，最后更新域
手册缺少某一部分没有按模板要求的四部分组织先建好四部分的标题框架再写内容

08环境与工具

现象原因解决
新建项目时找不到“Windows 窗体应用(.NET Framework)”Visual Studio 没有安装“.NET 桌面开发”工作负载，或搜索时选成了 .NET（非 Framework）的模板Visual Studio Installer 中修改安装；模板名称注意带“(.NET Framework)”
VS 中打开窗体设计器显示白屏或错误页项目未生成或 Designer.cs 有错误先重新生成解决方案，再看错误列表
模拟器启动报虚拟化相关错误BIOS 未开启虚拟化，或与其他虚拟化软件冲突练习机上按 Android 官方文档配置硬件加速；赛场电脑出现时举手
文件中文乱码文件编码不是 UTF-8代码、SQL 脚本统一保存为 UTF-8
做到一半断电或死机，代码没了没有及时保存Ctrl + Shift + S 养成习惯；定时备份文件夹
