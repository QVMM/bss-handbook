01赛事与评分

术语英文解释
模块Module赛题的组成部分，每个模块有独立的时间和分值。人社口商务软件解决方案常见为桌面、移动、测试等模块。
测量评分Measurement有客观对错的评分项，例如“输入错误密码时提示错误”，做到即得分。
评价评分Judgement由多名裁判按等级打分的评分项，例如界面美观、操作友好。
技术描述Technical Description（TD）世赛官方文件，规定赛项的能力要求、权重、评分和软件清单。资料包中的 TD09 即本赛项。
职业标准WSOSWorldSkills Occupational Standards，描述从业者“应该知道什么、能做什么”。
赛题公开 / 30% 变化Test Project change世赛惯例：赛前公开的题目在比赛时会做一定比例的修改。省赛的具体做法以当年技术文件为准。
工位Workstation每位选手的比赛电脑和桌面区域。
提交目录—赛题规定的成果保存位置，必须严格按要求命名和存放，否则可能无法评分。

02C# 与 .NET

术语英文解释
解决方案 / 项目Solution / Project.sln 是解决方案，可以包含多个 .csproj 项目（例如桌面端 + 接口 + 测试）。
命名空间Namespace给类分组的容器，using System.Data.SqlClient; 即引入命名空间。
类 / 对象Class / Object类是模板，对象是用 new 创建出来的实例。
属性Property带 get/set 的成员，例如 public string Name { get; set; }。
方法Method类中的函数。
静态static属于类本身而不属于某个对象，例如工具类 Db.Query()。
泛型集合List<T> / Dictionary<K,V>可变长度的列表和键值对表。
异常Exception运行时错误，用 try…catch 捕获，防止程序崩溃。
LINQLanguage Integrated Query在 C# 中用类似 SQL 的写法查询集合。
引用Reference项目依赖的程序集，例如图表控件需要引用 System.Windows.Forms.DataVisualization。
NuGetNuGet.NET 的包管理器。赛场能否使用以现场环境为准，建议准备不依赖 NuGet 的方案。

03数据库

术语英文解释
表 / 行 / 列Table / Row / Column数据库的基本结构，行也叫记录，列也叫字段。
主键Primary Key唯一标识一行的字段，不能重复、不能为空，常用自增 IDENTITY(1,1)。
外键Foreign Key指向另一张表主键的字段，用来表示表之间的关系。
约束Constraint对数据的限制：NOT NULL、UNIQUE、CHECK、DEFAULT 等。
连接JOIN把多张表按关联字段拼接查询；INNER JOIN 只保留匹配的行，LEFT JOIN 保留左表全部行。
聚合 / 分组Aggregate / GROUP BYCOUNT、SUM、AVG 等统计函数配合 GROUP BY 分组统计。
事务Transaction一组操作要么全部成功、要么全部撤销，例如下单时同时扣库存和写订单。
参数化查询Parameterized Query用 @参数 代替字符串拼接，防止 SQL 注入，也避免引号出错。
SQL 注入SQL Injection用户输入被当作 SQL 执行的安全漏洞。
ER 图Entity-Relationship Diagram用实体、属性和关系描述数据库设计的图。
数据字典Data Dictionary逐表逐字段说明名称、类型、约束和含义的文档。
范式Normal Form数据库设计规范，第三范式要求非主键字段只依赖主键，减少冗余。
备份 / 还原Backup / Restore.bak 文件的导出与导入；赛题也可能用 .sql 脚本提供数据。

04桌面应用（WinForms）

术语英文解释
窗体Form一个窗口。Show() 非模态打开，ShowDialog() 模态打开（关闭前不能操作父窗口）。
控件Control按钮、文本框、下拉框、表格等界面元素。
事件Event用户操作触发的代码，例如 Click、TextChanged、Load。
数据绑定Data Binding把 DataTable 或列表设为控件的 DataSource，自动显示数据。
DataGridView—表格控件，赛题中的列表页几乎都用它。
锚定 / 停靠Anchor / Dock控件随窗体大小变化的方式。
Tab 顺序TabIndex按 Tab 键时焦点移动的顺序，影响操作友好分。
应用设置Properties.Settings保存“记住我”等本地配置。
分页Paging每页显示固定条数，配合上一页 / 下一页按钮；SQL 中常用 OFFSET … FETCH。

05接口（Web API）

术语英文解释
接口API程序之间约定好的调用方式，手机端通过接口读写服务器数据库。
RESTRepresentational State Transfer用 URL 表示资源、用 HTTP 方法表示操作的接口风格。
HTTP 方法GET / POST / PUT / DELETE查询 / 新增 / 修改 / 删除。
状态码Status Code200 成功、204 成功无内容、400 请求错误、401 未认证、404 不存在、500 服务器错误。
JSONJavaScript Object Notation接口最常用的数据格式，例如 {"success":true,"data":[]}。
序列化Serialization把对象转成 JSON 字符串；反过来叫反序列化。
接口文档 / 契约API Contract写清楚每个接口的地址、方法、参数和返回格式，手机端和服务端按它开发。
Postman—接口调试工具，可以保存测试集合。
端口Port本手册的练习接口使用 5000 端口。
端口转发adb reverse让模拟器里的 localhost 指向电脑：adb reverse tcp:5000 tcp:5000。

06移动应用（Android）

术语英文解释
活动Activity一个界面页面，用 Intent 在页面之间跳转。
意图Intent页面跳转和调用系统功能（如拨号 ACTION_DIAL）的消息对象。
布局Layoutres/layout 中的 XML 文件，描述界面结构。
清单文件AndroidManifest.xml声明页面、权限（如 INTERNET）和应用配置。
主线程 / 子线程UI Thread / Background Thread网络请求必须在子线程，更新界面必须回到主线程（runOnUiThread）。
适配器Adapter把数据转换成列表中每一行的视图，例如 BaseAdapter。
轻量存储SharedPreferences保存登录状态、设置等少量数据。
传感器Sensor加速度传感器可用于“摇一摇”。
dp / sp—与屏幕密度无关的尺寸单位，文字用 sp，其他用 dp。
APKAndroid Package安装包，Module C 的测试对象就是 APK。
Gradle—Android Studio 的构建工具，离线环境需要提前准备缓存。

07需求与建模（UML）

术语英文解释
用例图Use Case Diagram参与者（小人）和他们能做的事（椭圆）。
类图Class Diagram类的属性、方法以及类之间的关联、继承关系。
活动图Activity Diagram业务流程图，有开始、结束、判断和分支。
时序图Sequence Diagram对象之间按时间顺序发送消息，适合画“登录”这种前后端交互。
参与者Actor系统外部的使用者，如客户、管理员、服务人员。
多重性Multiplicity关联两端的数量，如 1、0..*、1..*。
功能需求 / 非功能需求Functional / Non-functional“能做什么”与“做得怎么样”（性能、易用性、安全）。

08测试与文档

术语英文解释
测试用例Test Case编号、前置条件、步骤、输入、预期结果、实际结果。
缺陷Bug / Defect实际结果与预期不符。缺陷报告要写清复现步骤和严重程度。
等价类划分Equivalence Partitioning把输入分成有效 / 无效几类，每类选代表值测试。
边界值分析Boundary Value Analysis重点测试边界及其两侧，如长度 5、6、7。
黑盒 / 白盒测试Black-box / White-box不看代码只看功能 / 根据代码逻辑设计用例。
单元测试Unit Test对单个方法的自动化测试，本手册使用 MSTest。
断言Assert单元测试中判断结果是否符合预期的语句。
回归测试Regression Test修复缺陷后重新测试，确认没有引入新问题。
操作手册User Manual面向最终用户的使用说明，配截图和步骤。
