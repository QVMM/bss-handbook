01为什么是 WinForms

辽宁文件要求模块 A“使用 .NET 开发平台 Visual Studio 开发”，赛场提供 .NET Framework 4.8 及以上。在 .NET Framework 上做 Windows 桌面程序，主要有 WinForms 和 WPF 两种技术。辽宁样卷模块 A 登录界面截图的窗口标题是 FrmLogin，外观就是典型的 WinForms 窗体。WinForms 拖拽控件即可布局，学习曲线最平缓，数据表格控件 DataGridView 和图表控件 Chart 都是 .NET Framework 自带的，不依赖任何额外下载。本手册因此选择 WinForms。已经熟练掌握 WPF 的同学可以继续用 WPF，本章的数据访问、校验、分页思路完全通用。

02WinForms 入门：窗体、控件、事件

三个核心概念

  • 窗体（Form）：一个窗口。每个窗体由三个文件组成：FrmLogin.cs（你写的代码）、FrmLogin.Designer.cs（设计器自动生成，不要手动改）、FrmLogin.resx（资源）。
  • 控件（Control）：窗体上的按钮、文本框、表格等。从“工具箱”拖到窗体上，在“属性”窗口设置外观。
  • 事件（Event）：用户的动作（点击、输入、选择）触发的代码。双击按钮会自动生成它的 Click 事件方法。其他事件：选中控件 → 属性窗口顶部的闪电图标 → 找到事件名双击。

练习 6-1　热身：BMI 计算器

新建“Windows 窗体应用(.NET Framework)”项目 WarmUp。窗体上放：身高（cm）和体重（kg）两个文本框、一个“计算”按钮、一个显示结果的标签。点击计算：输入非数字或不在合理范围（身高 50–250、体重 20–300）时用 MessageBox 提示；否则显示“BMI：22.9（正常）”（BMI = 体重 / 身高米数²，保留 1 位；<18.5 偏瘦，18.5–24 正常，≥24 偏胖，练习用划分）。要求所有控件按规范命名，窗体启动时居中（StartPosition = CenterScreen），不能拉伸（FormBorderStyle = FixedSingle，MaximizeBox = False），按回车等于点击计算（窗体 AcceptButton = btnCalc）。

易错提醒

忘记添加 System.Configuration 引用时，ConfigurationManager 下面会出现红色波浪线，提示“当前上下文中不存在名称”。这不是代码写错，而是少了引用。

连接字符串

打开项目中的 App.config，在 <configuration> 内加入 connectionStrings 节：

App.config
<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <connectionStrings>
    <!-- Data Source：默认实例写 . ；Express 版写 .\SQLEXPRESS ；赛场以实际实例名为准 -->
    <add name="SmartCare"
         connectionString="Data Source=.;Initial Catalog=SmartCare;Integrated Security=True"
         providerName="System.Data.SqlClient" />
  </connectionStrings>
  <startup>
    <supportedRuntime version="v4.0" sku=".NETFramework,Version=v4.8" />
  </startup>
</configuration>
情况连接字符串
默认实例 + Windows 身份验证Data Source=.;Initial Catalog=SmartCare;Integrated Security=True
Express 命名实例Data Source=.\SQLEXPRESS;Initial Catalog=SmartCare;Integrated Security=True
SQL 身份验证（sa）Data Source=.;Initial Catalog=SmartCare;User ID=sa;Password=你的密码

连接字符串放在 App.config 里而不是写死在代码中，好处是：赛场实例名和你家里不一样时，只改这一处。程序编译后，App.config 会变成 bin\Debug\SmartCareDesk.exe.config，裁判换机器运行时也只需改这个文件。

数据访问帮助类 DbHelper

新建类文件 DbHelper.cs。它提供三个方法：查询（返回 DataTable）、执行增删改（返回影响行数）、取单个值。所有 SQL 都用参数（@名字）传值，绝不拼接用户输入。

DbHelper.cs
using System;
using System.Configuration;
using System.Data;
using System.Data.SqlClient;

namespace SmartCareDesk
{
    /// <summary>
    /// 数据访问帮助类：所有 SQL 都通过这里执行，统一使用参数化查询。
    /// </summary>
    public static class DbHelper
    {
        // 连接字符串写在 App.config 中，名字叫 SmartCare
        private static readonly string ConnStr =
            ConfigurationManager.ConnectionStrings["SmartCare"].ConnectionString;

        /// <summary>执行查询，返回一张 DataTable。</summary>
        public static DataTable Query(string sql, params SqlParameter[] ps)
        {
            using (SqlConnection conn = new SqlConnection(ConnStr))
            using (SqlCommand cmd = new SqlCommand(sql, conn))
            {
                if (ps != null) cmd.Parameters.AddRange(ps);
                SqlDataAdapter da = new SqlDataAdapter(cmd);
                DataTable dt = new DataTable();
                da.Fill(dt);              // Fill 会自动打开和关闭连接
                return dt;
            }
        }

        /// <summary>执行增删改，返回受影响的行数。</summary>
        public static int Execute(string sql, params SqlParameter[] ps)
        {
            using (SqlConnection conn = new SqlConnection(ConnStr))
            using (SqlCommand cmd = new SqlCommand(sql, conn))
            {
                if (ps != null) cmd.Parameters.AddRange(ps);
                conn.Open();
                return cmd.ExecuteNonQuery();
            }
        }

        /// <summary>执行查询，返回第一行第一列（如 COUNT(*)、SCOPE_IDENTITY()）。</summary>
        public static object Scalar(string sql, params SqlParameter[] ps)
        {
            using (SqlConnection conn = new SqlConnection(ConnStr))
            using (SqlCommand cmd = new SqlCommand(sql, conn))
            {
                if (ps != null) cmd.Parameters.AddRange(ps);
                conn.Open();
                object v = cmd.ExecuteScalar();
                return v == DBNull.Value ? null : v;
            }
        }
    }
}
易错提醒：为什么一定要参数化

如果写成 "... WHERE UserName = '" + txtUserName.Text + "'"，用户名里只要有一个单引号（例如 O'Neil）SQL 就会报错；更严重的是，输入 ' OR '1'='1 可以不用密码直接登录（SQL 注入）。裁判可能会专门测试这种输入，评价分里的“安全”也会关注这一点。

易错提醒：SqlParameter 的数字 0 陷阱

new SqlParameter("@s", 0) 中的 0 会被编译器当成 SqlDbType 枚举值，而不是参数值，结果参数没有值，执行报错。传整数时统一写成 new SqlParameter("@s", SqlDbType.Int) { Value = 0 }，本章代码都采用这种写法。

再新建 Validator.cs（直接用第 04 章练习 4-7 的成果）和 Session.cs（保存当前登录者）：

Validator.cs
using System.Text.RegularExpressions;

namespace SmartCareDesk
{
    /// <summary>输入校验规则集中放在这里，桌面端各窗体共用。</summary>
    public static class Validator
    {
        public static bool IsPhone(string s)    { return Regex.IsMatch(s ?? "", @"^\d{11}$"); }
        public static bool IsPassword(string s) { return Regex.IsMatch(s ?? "", @"^(?=.*[A-Za-z])(?=.*\d).{8,}$"); }

        /// <summary>校验注册信息，返回第一条错误；全部通过返回空字符串。</summary>
        public static string ValidateRegister(string user, string pwd, string pwd2, string phone)
        {
            if (string.IsNullOrWhiteSpace(user)) return "用户名不能为空";
            if (!IsPassword(pwd)) return "密码至少 8 位，且必须同时包含字母和数字";
            if (pwd != pwd2) return "两次输入的密码不一致";
            if (!IsPhone(phone)) return "联系电话必须是 11 位数字";
            return "";
        }
    }
}

添加 → 窗体(Windows 窗体)，命名 FrmLogin。按下表放置控件（位置参考辽宁样卷 1.1 的截图：Logo 与标题居中，下方用户名、密码、记住密码、登录按钮、注册链接）：

控件Name关键属性

用“设置”保存记住的密码

“记住密码”需要把用户名和密码保存在本机，下次启动时读出。最简单的办法是项目自带的“设置”：

  1. 解决方案资源管理器 → 项目 → Properties → 双击 Settings.settings（没有就右键项目 → 属性 → 设置 → 点击创建）。
  2. 添加三行，范围都选“用户”：SavedUser（string）、SavedPwd（string）、RememberPwd（bool，值 False）。
  3. 代码中用 Properties.Settings.Default.SavedUser 读写，修改后调用 Properties.Settings.Default.Save() 保存。

“用户”范围的设置保存在当前 Windows 用户的配置目录中，重新编译不会丢失。

代码

FrmLogin.cs
using System;
using System.Data;
using System.Data.SqlClient;
using System.Windows.Forms;

namespace SmartCareDesk
{
    public partial class FrmLogin : Form
    {
        public FrmLogin()
        {
            InitializeComponent();
        }

        // 窗体加载：如果上次勾选了“记住密码”，自动填入
        private void FrmLogin_Load(object sender, EventArgs e)
        {
            FillRemembered();
        }

        private void FillRemembered()
        {
            var st = Properties.Settings.Default;
            chkRemember.Checked = st.RememberPwd;
            txtUserName.Text = st.RememberPwd ? st.SavedUser : "";
            txtPassword.Text = st.RememberPwd ? st.SavedPwd : "";
        }

        private void btnLogin_Click(object sender, EventArgs e)
        {
            string user = txtUserName.Text.Trim();
            string pwd = txtPassword.Text;
            if (user == "" || pwd == "")
            {
                MessageBox.Show("请输入用户名和密码", "提示", MessageBoxButtons.OK, MessageBoxIcon.Warning);
                return;
            }

            DataTable dt;
            try
            {
                dt = DbHelper.Query(
                    "SELECT ManagerId, UserName FROM Manager WHERE UserName = @u AND Password = @p",
                    new SqlParameter("@u", user), new SqlParameter("@p", pwd));
            }
            catch (Exception ex)
            {
                MessageBox.Show("无法连接数据库：" + ex.Message, "错误", MessageBoxButtons.OK, MessageBoxIcon.Error);
                return;
            }

            if (dt.Rows.Count == 0)
            {
                MessageBox.Show("用户名或密码错误", "登录失败", MessageBoxButtons.OK, MessageBoxIcon.Error);
                txtPassword.Clear();
                txtPassword.Focus();
                return;
            }

            Session.ManagerId = Convert.ToInt32(dt.Rows[0]["ManagerId"]);
            Session.UserName = dt.Rows[0]["UserName"].ToString();

            // 记住密码：勾选则保存，不勾选则清除
            var st = Properties.Settings.Default;
            st.RememberPwd = chkRemember.Checked;
            st.SavedUser = chkRemember.Checked ? user : "";
            st.SavedPwd = chkRemember.Checked ? pwd : "";
            st.Save();

            // 打开首页（用户管理），隐藏登录窗
            FrmUserManage main = new FrmUserManage();
            main.FormClosed += (s, args) =>
            {
                if (main.IsLogout) { FillRemembered(); this.Show(); }
                else this.Close();          // 关闭登录窗 = 退出程序
            };
            main.Show();
            this.Hide();
        }

        private void lnkRegister_LinkClicked(object sender, LinkLabelLinkClickedEventArgs e)
        {
            using (FrmRegister f = new FrmRegister())
            {
                if (f.ShowDialog(this) == DialogResult.OK)
                {
                    txtUserName.Text = f.RegisteredUserName;   // 注册成功后自动填入用户名
                    txtPassword.Clear();
                    txtPassword.Focus();
                }
            }
        }
    }
}

记得把 FrmLogin_Load 绑定到窗体的 Load 事件（双击窗体空白处即可自动生成并绑定）。最后在 Program.cs 中把启动窗体改为 FrmLogin：

训练建议：主窗体与登录窗体的关系

Application.Run(new FrmLogin()) 让登录窗体成为“主窗体”，它关闭程序就退出。所以登录成功后我们只是 Hide() 登录窗，而不是关闭它；首页关闭时再根据“注销”还是“退出”决定是重新显示登录窗，还是关闭它结束程序。这是比赛中最常用、最不容易出错的模式。

练习 6-2　登录自测

导入练习库后运行程序，逐项测试并记录结果：① 用户名或密码为空；② admin + 错误密码；③ admin + admin123 不勾选记住密码，登录后注销，看登录框是否清空；④ 勾选记住密码登录，关闭程序再打开，看是否自动填入；⑤ 用户名输入 ' OR '1'='1、密码随便输，确认不能登录；⑥ 在 App.config 中把数据库名改错，看是否给出友好提示而不是崩溃。

05注册窗体：完整的校验流程

控件Name说明
TextBoxtxtUserName用户名
TextBoxtxtPassword、txtPassword2密码、确认密码；UseSystemPasswordChar = True
TextBoxtxtPhone联系电话；MaxLength = 11
LabellblRule灰色小字提示规则：“密码至少 8 位，需包含字母和数字”
ButtonbtnSubmit、btnCancelbtnCancel 的 ForeColor 设为红色（不少题目要求 Cancel/Delete 为红色）
FrmRegister.cs
using System;
using System.Data.SqlClient;
using System.Windows.Forms;

namespace SmartCareDesk
{
    public partial class FrmRegister : Form
    {
        public string RegisteredUserName { get; private set; }

        public FrmRegister()
        {
            InitializeComponent();
        }

        private void btnSubmit_Click(object sender, EventArgs e)
        {
            string user = txtUserName.Text.Trim();
            string pwd = txtPassword.Text;
            string pwd2 = txtPassword2.Text;
            string phone = txtPhone.Text.Trim();

            // 1. 格式校验
            string err = Validator.ValidateRegister(user, pwd, pwd2, phone);
            if (err != "")
            {
                MessageBox.Show(err, "提示", MessageBoxButtons.OK, MessageBoxIcon.Warning);
                return;
            }

            try
            {
                // 2. 唯一性校验
                int exists = Convert.ToInt32(DbHelper.Scalar(
                    "SELECT COUNT(*) FROM Manager WHERE UserName = @u", new SqlParameter("@u", user)));
                if (exists > 0)
                {
                    MessageBox.Show("用户名已存在，请换一个", "提示", MessageBoxButtons.OK, MessageBoxIcon.Warning);
                    txtUserName.Focus();
                    return;
                }

                // 3. 写入数据库
                DbHelper.Execute(
                    "INSERT INTO Manager (UserName, Password, Phone) VALUES (@u, @p, @ph)",
                    new SqlParameter("@u", user), new SqlParameter("@p", pwd), new SqlParameter("@ph", phone));
            }
            catch (Exception ex)
            {
                MessageBox.Show("注册失败：" + ex.Message, "错误", MessageBoxButtons.OK, MessageBoxIcon.Error);
                return;
            }

            MessageBox.Show("注册成功，请登录", "提示", MessageBoxButtons.OK, MessageBoxIcon.Information);
            RegisteredUserName = user;
            DialogResult = DialogResult.OK;    // 对话框模式下，设置 DialogResult 会自动关闭窗体
        }

        private void btnCancel_Click(object sender, EventArgs e)
        {
            DialogResult = DialogResult.Cancel;
        }
    }
}

校验顺序是“格式 → 唯一性 → 写入”。先在本地把能判断的都判断完，再访问数据库，既快又能给出最准确的提示。

训练建议：提示信息要“明确”

辽宁样卷要求“用户名重复、密码不一致、格式错误需给出明确提示”。“输入有误”不算明确；“两次输入的密码不一致”才算。每条提示都要让用户知道哪里错了、该怎么改。此外，可以考虑在用户离开输入框时（Leave 事件）就即时校验，并用 ErrorProvider 在输入框旁显示红色图标——这类细节容易在评价分上体现出“高于行业标准”。

06首页：用户列表、查询与分页

辽宁样卷写明登录成功后进入“系统首页（用户管理界面）”。用户管理是比赛中最典型的界面：查询条件 + 表格 + 分页 + 新增/编辑/删除按钮。湖北评分表中的“用户管理”就有界面元素、按条件查询、字段显示、每页 10 条、分页按钮、页码跳转、编辑/新增跳转等十余个细项。

FrmUserManage.cs
using System;
using System.Collections.Generic;
using System.Data;
using System.Data.SqlClient;
using System.Drawing;
using System.Windows.Forms;

namespace SmartCareDesk
{
    public partial class FrmUserManage : Form
    {
        private const int PageSize = 10;
        private int _pageIndex = 1;     // 当前页，从 1 开始
        private int _pageCount = 1;     // 总页数
        private bool _loading;          // 正在填充页码下拉框时，忽略它的选择事件

        /// <summary>点击“注销”时为 true，登录窗据此决定是重新显示还是退出程序。</summary>
        public bool IsLogout { get; private set; }

        public FrmUserManage()
        {
            InitializeComponent();
        }

        private void FrmUserManage_Load(object sender, EventArgs e)
        {
            lblWelcome.Text = "欢迎，" + Session.UserName;
            cboStatus.Items.AddRange(new object[] { "全部", "正常", "禁用" });
            cboStatus.SelectedIndex = 0;

            dgvUsers.ReadOnly = true;
            dgvUsers.AllowUserToAddRows = false;      // 去掉最后一行空白行
            dgvUsers.SelectionMode = DataGridViewSelectionMode.FullRowSelect;
            dgvUsers.MultiSelect = false;
            dgvUsers.AutoSizeColumnsMode = DataGridViewAutoSizeColumnsMode.Fill;
            dgvUsers.RowHeadersVisible = false;

            LoadData();
        }

        /// <summary>按当前查询条件和页码加载数据。</summary>
        private void LoadData()
        {
            // 1. 拼接查询条件（只拼“条件结构”，值一律用参数）
            string where = " WHERE 1 = 1";
            List<SqlParameter> ps = new List<SqlParameter>();
            string kw = txtKeyword.Text.Trim();
            if (kw != "")
            {
                where += " AND (RealName LIKE @kw OR Phone LIKE @kw)";
                ps.Add(new SqlParameter("@kw", "%" + kw + "%"));
            }
            if (cboStatus.SelectedIndex == 1) where += " AND Status = 1";
            if (cboStatus.SelectedIndex == 2) where += " AND Status = 0";

            try
            {
                // 2. 先查总数，算总页数
                int total = Convert.ToInt32(DbHelper.Scalar("SELECT COUNT(*) FROM Customer" + where, CloneParams(ps)));
                _pageCount = Math.Max(1, (total + PageSize - 1) / PageSize);
                if (_pageIndex > _pageCount) _pageIndex = _pageCount;
                if (_pageIndex < 1) _pageIndex = 1;

                // 3. 再查当前页
                string sql = @"SELECT CustomerId, ISNULL(RealName, N'') AS RealName, ISNULL(Gender, N'') AS Gender,
                                      BirthDate, Phone, ISNULL(Address, N'') AS Address,
                                      CASE Status WHEN 1 THEN N'正常' ELSE N'禁用' END AS StatusText, CreatedAt
                               FROM Customer" + where + @"
                               ORDER BY CustomerId
                               OFFSET @skip ROWS FETCH NEXT @take ROWS ONLY";
                List<SqlParameter> ps2 = new List<SqlParameter>(CloneParams(ps));
                ps2.Add(new SqlParameter("@skip", SqlDbType.Int) { Value = (_pageIndex - 1) * PageSize });
                ps2.Add(new SqlParameter("@take", SqlDbType.Int) { Value = PageSize });
                dgvUsers.DataSource = DbHelper.Query(sql, ps2.ToArray());

                SetupColumns();
                lblPageInfo.Text = string.Format("共 {0} 条，第 {1}/{2} 页", total, _pageIndex, _pageCount);
                FillPageCombo();
                UpdatePagerButtons();
            }
            catch (Exception ex)
            {
                MessageBox.Show("加载数据失败：" + ex.Message, "错误", MessageBoxButtons.OK, MessageBoxIcon.Error);
            }
        }

        // SqlParameter 对象不能同时属于两个命令，所以每次执行前复制一份
        private static SqlParameter[] CloneParams(List<SqlParameter> src)
        {
            List<SqlParameter> list = new List<SqlParameter>();
            foreach (SqlParameter p in src) list.Add(new SqlParameter(p.ParameterName, p.Value));
            return list.ToArray();
        }

        private void SetupColumns()
        {
            dgvUsers.Columns["CustomerId"].HeaderText = "编号";
            dgvUsers.Columns["RealName"].HeaderText = "姓名";
            dgvUsers.Columns["Gender"].HeaderText = "性别";
            dgvUsers.Columns["BirthDate"].HeaderText = "出生日期";
            dgvUsers.Columns["BirthDate"].DefaultCellStyle.Format = "yyyy-MM-dd";
            dgvUsers.Columns["Phone"].HeaderText = "手机号";
            dgvUsers.Columns["Address"].HeaderText = "地址";
            dgvUsers.Columns["StatusText"].HeaderText = "状态";
            dgvUsers.Columns["CreatedAt"].HeaderText = "注册时间";
            dgvUsers.Columns["CreatedAt"].DefaultCellStyle.Format = "yyyy-MM-dd HH:mm";
        }

        private void FillPageCombo()
        {
            _loading = true;
            cboPage.Items.Clear();
            for (int i = 1; i <= _pageCount; i++) cboPage.Items.Add(i);
            cboPage.SelectedIndex = _pageIndex - 1;
            _loading = false;
        }

        private void UpdatePagerButtons()
        {
            btnFirst.Enabled = btnPrev.Enabled = _pageIndex > 1;
            btnNext.Enabled = btnLast.Enabled = _pageIndex < _pageCount;
        }

        // 被禁用的客户整行显示为浅红色（界面上要有图例说明颜色含义）
        private void dgvUsers_CellFormatting(object sender, DataGridViewCellFormattingEventArgs e)
        {
            if (e.RowIndex < 0) return;
            DataGridViewRow row = dgvUsers.Rows[e.RowIndex];
            if (Convert.ToString(row.Cells["StatusText"].Value) == "禁用")
                e.CellStyle.BackColor = Color.MistyRose;
        }

        private void btnSearch_Click(object sender, EventArgs e) { _pageIndex = 1; LoadData(); }
        private void btnFirst_Click(object sender, EventArgs e)  { _pageIndex = 1; LoadData(); }
        private void btnPrev_Click(object sender, EventArgs e)   { _pageIndex--; LoadData(); }
        private void btnNext_Click(object sender, EventArgs e)   { _pageIndex++; LoadData(); }
        private void btnLast_Click(object sender, EventArgs e)   { _pageIndex = _pageCount; LoadData(); }

        private void cboPage_SelectedIndexChanged(object sender, EventArgs e)
        {
            if (_loading || cboPage.SelectedIndex < 0) return;
            _pageIndex = cboPage.SelectedIndex + 1;
            LoadData();
        }

        /// <summary>取当前选中行的客户编号；没有选中返回 0。</summary>
        private int SelectedId()
        {
            if (dgvUsers.CurrentRow == null) return 0;
            return Convert.ToInt32(dgvUsers.CurrentRow.Cells["CustomerId"].Value);
        }

        private void btnAdd_Click(object sender, EventArgs e)
        {
            using (FrmUserEdit f = new FrmUserEdit(0))
            {
                if (f.ShowDialog(this) == DialogResult.OK) LoadData();
            }
        }

        private void btnEdit_Click(object sender, EventArgs e)
        {
            int id = SelectedId();
            if (id == 0) { MessageBox.Show("请先选择一位客户", "提示"); return; }
            using (FrmUserEdit f = new FrmUserEdit(id))
            {
                if (f.ShowDialog(this) == DialogResult.OK) LoadData();
            }
        }

        // 双击行 = 编辑，符合用户习惯
        private void dgvUsers_CellDoubleClick(object sender, DataGridViewCellEventArgs e)
        {
            if (e.RowIndex >= 0) btnEdit_Click(sender, EventArgs.Empty);
        }

        // 禁用 / 启用（软删除）
        private void btnToggle_Click(object sender, EventArgs e)
        {
            int id = SelectedId();
            if (id == 0) { MessageBox.Show("请先选择一位客户", "提示"); return; }
            string name = Convert.ToString(dgvUsers.CurrentRow.Cells["RealName"].Value);
            bool disabled = Convert.ToString(dgvUsers.CurrentRow.Cells["StatusText"].Value) == "禁用";
            string action = disabled ? "启用" : "禁用";
            if (MessageBox.Show("确定要" + action + "客户“" + name + "”吗？", "确认",
                MessageBoxButtons.YesNo, MessageBoxIcon.Question) != DialogResult.Yes) return;

            DbHelper.Execute("UPDATE Customer SET Status = @s WHERE CustomerId = @id",
                new SqlParameter("@s", SqlDbType.TinyInt) { Value = disabled ? 1 : 0 },
                new SqlParameter("@id", SqlDbType.Int) { Value = id });
            LoadData();
        }

        private void btnStatistics_Click(object sender, EventArgs e)
        {
            using (FrmStatistics f = new FrmStatistics()) f.ShowDialog(this);
        }

        private void btnLogout_Click(object sender, EventArgs e)
        {
            if (MessageBox.Show("确定要注销并返回登录界面吗？", "确认", MessageBoxButtons.YesNo,
                MessageBoxIcon.Question) != DialogResult.Yes) return;
            IsLogout = true;
            Close();
        }

        // 点右上角关闭：确认是否退出
        private void FrmUserManage_FormClosing(object sender, FormClosingEventArgs e)
        {
            if (IsLogout) return;
            if (MessageBox.Show("确定要退出系统吗？", "确认", MessageBoxButtons.YesNo,
                MessageBoxIcon.Question) != DialogResult.Yes) e.Cancel = true;
        }
    }
}

这段代码覆盖了哪些得分点

  • 模糊查询（姓名或手机号）与状态筛选可以组合
  • 每页 10 条；不足 10 条只显示实际行数，没有空白行（AllowUserToAddRows = false）
  • 首页、上一页、下一页、尾页、页码下拉跳转；在第一页时“上一页”不可点
  • 显示“共 N 条，第 x/y 页”
  • 日期按 yyyy-MM-dd 显示
  • 禁用的客户整行变色，并有图例说明颜色含义
  • 数据超出表格区域时，DataGridView 自动出现滚动条，否则不显示（默认行为即满足题目的滚动条要求，不要把 ScrollBars 设成 None）
  • 禁用前确认；操作后列表立即刷新
  • 退出确认；注销返回登录
易错提醒：查询后页码不回到第 1 页

用户在第 3 页时输入新条件查询，结果只有 1 页，如果页码还停在 3，就会显示空表。代码中 btnSearch_Click 先把 _pageIndex = 1，LoadData 中又把页码限制在 1 到总页数之间，两道保险。

07新增与编辑：一个窗体两种模式

新增和编辑的界面几乎一样，用同一个窗体，通过构造函数参数区分：new FrmUserEdit(0) 是新增，new FrmUserEdit(编号) 是编辑。以 ShowDialog 方式打开（模态对话框），保存成功返回 DialogResult.OK，列表据此刷新。

图片：默认图片与不锁文件

辽宁样卷要求“需要加载图片时，如果没有提供对应图片，显示默认图片 default.jpg”。把题目给的图片和 default.jpg 放到项目的 Images 文件夹，选中这些文件，在属性窗口把“复制到输出目录”设为“如果较新则复制”，它们就会跟着程序出现在 bin\Debug\Images\ 下。

ImageHelper.cs
using System.Drawing;
using System.IO;

namespace SmartCareDesk
{
    public static class ImageHelper
    {
        /// <summary>
        /// 从程序目录下的 Images 文件夹加载图片；文件名为空或文件不存在时加载 default.jpg。
        /// 先读入内存再创建 Image，避免图片文件被程序占用（锁定）。
        /// </summary>
        public static Image Load(string fileName)
        {
            string dir = Path.Combine(System.AppDomain.CurrentDomain.BaseDirectory, "Images");
            string path = string.IsNullOrWhiteSpace(fileName) ? null : Path.Combine(dir, fileName);
            if (path == null || !File.Exists(path)) path = Path.Combine(dir, "default.jpg");
            if (!File.Exists(path)) return null;
            byte[] bytes = File.ReadAllBytes(path);
            using (MemoryStream ms = new MemoryStream(bytes))
            {
                return new Bitmap(Image.FromStream(ms));
            }
        }
    }
}
易错提醒：Image.FromFile 会锁住文件

用 Image.FromFile(path) 加载的图片，在程序关闭前文件一直被占用；如果用户接着要替换这张照片，File.Copy 会报“文件正由另一进程使用”。上面的写法先把字节读进内存再创建图片，避免了这个问题。

编辑窗体代码

控件：txtName、cboGender、dtpBirth、txtPhone、txtAddress、picAvatar（SizeMode = Zoom）、btnChoosePhoto、btnSave、btnCancel（红色）。

FrmUserEdit.cs
using System;
using System.Data;
using System.Data.SqlClient;
using System.IO;
using System.Windows.Forms;

namespace SmartCareDesk
{
    public partial class FrmUserEdit : Form
    {
        private readonly int _id;          // 0 表示新增，大于 0 表示编辑
        private string _avatarName;        // 数据库中保存的图片文件名
        private string _newPhotoPath;      // 本次新选择的图片（尚未复制）

        public FrmUserEdit(int id)
        {
            InitializeComponent();
            _id = id;
        }

        private void FrmUserEdit_Load(object sender, EventArgs e)
        {
            cboGender.DropDownStyle = ComboBoxStyle.DropDownList;   // 只能选，不能乱输
            cboGender.Items.AddRange(new object[] { "男", "女" });
            dtpBirth.Format = DateTimePickerFormat.Custom;
            dtpBirth.CustomFormat = "yyyy-MM-dd";
            dtpBirth.MaxDate = DateTime.Today;                       // 出生日期不能晚于今天

            if (_id == 0)
            {
                Text = "新增客户";
                picAvatar.Image = ImageHelper.Load(null);
                return;
            }

            Text = "编辑客户";
            txtPhone.ReadOnly = true;     // 手机号是登录账号，编辑时不允许修改
            DataTable dt = DbHelper.Query("SELECT * FROM Customer WHERE CustomerId = @id",
                new SqlParameter("@id", SqlDbType.Int) { Value = _id });
            if (dt.Rows.Count == 0) { MessageBox.Show("该客户不存在"); Close(); return; }
            DataRow r = dt.Rows[0];
            txtName.Text = Convert.ToString(r["RealName"]);
            txtPhone.Text = Convert.ToString(r["Phone"]);
            txtAddress.Text = Convert.ToString(r["Address"]);
            cboGender.SelectedItem = Convert.ToString(r["Gender"]);
            if (r["BirthDate"] != DBNull.Value) dtpBirth.Value = Convert.ToDateTime(r["BirthDate"]);
            _avatarName = Convert.ToString(r["Avatar"]);
            picAvatar.Image = ImageHelper.Load(_avatarName);
        }

        private void btnChoosePhoto_Click(object sender, EventArgs e)
        {
            using (OpenFileDialog dlg = new OpenFileDialog())
            {
                dlg.Filter = "图片文件|*.jpg;*.jpeg;*.png";
                if (dlg.ShowDialog(this) != DialogResult.OK) return;
                if (new FileInfo(dlg.FileName).Length > 100 * 1024)
                {
                    MessageBox.Show("照片不能超过 100KB", "提示", MessageBoxButtons.OK, MessageBoxIcon.Warning);
                    return;
                }
                _newPhotoPath = dlg.FileName;
                picAvatar.ImageLocation = _newPhotoPath;   // 先预览
            }
        }

        private void btnSave_Click(object sender, EventArgs e)
        {
            string name = txtName.Text.Trim();
            string phone = txtPhone.Text.Trim();
            if (name == "") { MessageBox.Show("请输入姓名"); txtName.Focus(); return; }
            if (!Validator.IsPhone(phone)) { MessageBox.Show("手机号必须是 11 位数字"); txtPhone.Focus(); return; }
            if (cboGender.SelectedIndex < 0) { MessageBox.Show("请选择性别"); return; }

            try
            {
                if (_id == 0)
                {
                    int exists = Convert.ToInt32(DbHelper.Scalar(
                        "SELECT COUNT(*) FROM Customer WHERE Phone = @ph", new SqlParameter("@ph", phone)));
                    if (exists > 0) { MessageBox.Show("该手机号已注册"); return; }
                }

                // 复制新照片到 Images 文件夹，文件名用“手机号_时间戳”避免重名
                if (_newPhotoPath != null)
                {
                    string dir = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "Images");
                    Directory.CreateDirectory(dir);
                    _avatarName = phone + "_" + DateTime.Now.ToString("yyyyMMddHHmmss") + Path.GetExtension(_newPhotoPath);
                    File.Copy(_newPhotoPath, Path.Combine(dir, _avatarName), true);
                }

                SqlParameter[] ps =
                {
                    new SqlParameter("@name", name),
                    new SqlParameter("@gender", cboGender.SelectedItem.ToString()),
                    new SqlParameter("@birth", SqlDbType.Date) { Value = dtpBirth.Value.Date },
                    new SqlParameter("@addr", txtAddress.Text.Trim()),
                    new SqlParameter("@avatar", (object)_avatarName ?? DBNull.Value),
                    new SqlParameter("@phone", phone),
                    new SqlParameter("@id", SqlDbType.Int) { Value = _id }
                };

                if (_id == 0)
                    DbHelper.Execute(@"INSERT INTO Customer (Phone, Password, RealName, Gender, BirthDate, Address, Avatar)
                                       VALUES (@phone, 'sc' + RIGHT(@phone, 6), @name, @gender, @birth, @addr, @avatar)", ps);
                else
                    DbHelper.Execute(@"UPDATE Customer SET RealName = @name, Gender = @gender, BirthDate = @birth,
                                       Address = @addr, Avatar = @avatar WHERE CustomerId = @id", ps);
            }
            catch (Exception ex)
            {
                MessageBox.Show("保存失败：" + ex.Message, "错误", MessageBoxButtons.OK, MessageBoxIcon.Error);
                return;
            }

            MessageBox.Show("保存成功", "提示");
            DialogResult = DialogResult.OK;
        }

        private void btnCancel_Click(object sender, EventArgs e)
        {
            DialogResult = DialogResult.Cancel;
        }
    }
}

值得注意的细节：

  • 性别下拉框设为 DropDownList，只能选不能乱输；出生日期最大值为今天。
  • 编辑时手机号只读——它是登录账号（湖北样题“Email 不可修改”是同一类要求）。
  • 照片限制 100KB（湖北样题原有要求），选择后先预览，保存时才复制，并换成不会重名的文件名。
  • 新增客户时的初始密码规则（“sc”+手机号后 6 位）是本练习自拟的；比赛中按题目规定实现。
  • INSERT 和 UPDATE 共用一组参数；SQL 中没用到的参数会被忽略，不影响执行。

08统计与图表

比赛中经常要求“统计结果以表格和图表显示”（湖北样题“机票统计”：数据网格 + 折线图，可通过 View by 切换显示的数据，勾选 Show Amount 时折线上显示数值）。.NET Framework 自带 Chart 控件，在工具箱“数据”分组中（如果没有，先确认已添加 System.Windows.Forms.DataVisualization 引用，再右键工具箱 → 选择项 → 勾选 Chart）。

界面

dtpFrom、dtpTo（统计时间范围）、cboViewBy（订单数/营业额）、chkShowValue（显示数值）、btnStat、dgvStat（左侧或上方）、chart1（右侧或下方）。

FrmStatistics.cs
using System;
using System.Data;
using System.Data.SqlClient;
using System.Windows.Forms;
using System.Windows.Forms.DataVisualization.Charting;

namespace SmartCareDesk
{
    public partial class FrmStatistics : Form
    {
        private DataTable _data;

        public FrmStatistics()
        {
            InitializeComponent();
        }

        private void FrmStatistics_Load(object sender, EventArgs e)
        {
            dtpFrom.Format = dtpTo.Format = DateTimePickerFormat.Custom;
            dtpFrom.CustomFormat = dtpTo.CustomFormat = "yyyy-MM-dd";
            dtpFrom.Value = new DateTime(DateTime.Today.Year, 1, 1);
            dtpTo.Value = DateTime.Today;
            cboViewBy.DropDownStyle = ComboBoxStyle.DropDownList;
            cboViewBy.Items.AddRange(new object[] { "订单数", "营业额" });
            cboViewBy.SelectedIndex = 0;
            chkShowValue.Checked = true;
            dgvStat.ReadOnly = true;
            dgvStat.AllowUserToAddRows = false;
            dgvStat.RowHeadersVisible = false;
            dgvStat.AutoSizeColumnsMode = DataGridViewAutoSizeColumnsMode.Fill;
        }

        private void btnStat_Click(object sender, EventArgs e)
        {
            if (dtpFrom.Value.Date > dtpTo.Value.Date)
            {
                MessageBox.Show("开始日期不能晚于结束日期", "提示");
                return;
            }
            _data = DbHelper.Query(@"
                SELECT CONVERT(CHAR(7), CreatedAt, 120) AS [Month],
                       COUNT(*) AS OrderCount,
                       SUM(Amount) AS Revenue
                FROM ServiceOrder
                WHERE Status <> 3 AND CreatedAt >= @from AND CreatedAt < @to
                GROUP BY CONVERT(CHAR(7), CreatedAt, 120)
                ORDER BY [Month]",
                new SqlParameter("@from", SqlDbType.DateTime) { Value = dtpFrom.Value.Date },
                new SqlParameter("@to", SqlDbType.DateTime) { Value = dtpTo.Value.Date.AddDays(1) });  // 包含结束当天

            dgvStat.DataSource = _data;
            dgvStat.Columns["Month"].HeaderText = "月份";
            dgvStat.Columns["OrderCount"].HeaderText = "订单数";
            dgvStat.Columns["Revenue"].HeaderText = "营业额（元）";
            dgvStat.Columns["Revenue"].DefaultCellStyle.Format = "0.00";
            DrawChart();
        }

        private void DrawChart()
        {
            if (_data == null) return;
            chart1.Series.Clear();
            string col = cboViewBy.SelectedIndex == 0 ? "OrderCount" : "Revenue";
            Series s = new Series(cboViewBy.Text);
            s.ChartType = SeriesChartType.Line;
            s.BorderWidth = 3;
            s.MarkerStyle = MarkerStyle.Circle;
            s.IsValueShownAsLabel = chkShowValue.Checked;   // 是否在折线上显示数值
            foreach (DataRow r in _data.Rows)
                s.Points.AddXY(r["Month"].ToString(), Convert.ToDouble(r[col]));
            chart1.Series.Add(s);
            chart1.ChartAreas[0].AxisX.Interval = 1;
            chart1.ChartAreas[0].AxisX.MajorGrid.Enabled = false;
        }

        // 切换“查看”方式或“显示数值”时，图表立即刷新
        private void cboViewBy_SelectedIndexChanged(object sender, EventArgs e) { DrawChart(); }
        private void chkShowValue_CheckedChanged(object sender, EventArgs e)   { DrawChart(); }
    }
}
  • 结束日期“包含当天”：条件写成 CreatedAt < 结束日期 + 1 天，不要写 <= 结束日期（那样会漏掉当天 00:00 以后的记录）。
  • 切换“查看方式”和“显示数值”时立即重画，不需要再点统计按钮——这正是评分表中“自动更新数据信息”一类的细项。
  • 改成柱状图：SeriesChartType.Column；饼图：SeriesChartType.Pie，饼图显示百分比：s.Label = "#VALX #PERCENT{P1}";。

验证码（失败 3 次后出现）

湖北样题：登录失败 3 次后出现验证码，4 位同时包含字母和数字，点击验证码可刷新。

Captcha.cs
using System;
using System.Text;

namespace SmartCareDesk
{
    public static class Captcha
    {
        private static readonly Random Rnd = new Random();
        private const string Letters = "ABCDEFGHJKLMNPQRSTUVWXYZabcdefghjkmnpqrstuvwxyz";  // 去掉易混淆的 I、O、l、o
        private const string Digits = "23456789";                                      // 去掉 0、1

        /// <summary>生成指定长度、同时包含字母和数字的验证码。</summary>
        public static string Create(int length)
        {
            StringBuilder sb = new StringBuilder();
            sb.Append(Letters[Rnd.Next(Letters.Length)]);      // 保证至少一个字母
            sb.Append(Digits[Rnd.Next(Digits.Length)]);        // 保证至少一个数字
            string all = Letters + Digits;
            while (sb.Length < length) sb.Append(all[Rnd.Next(all.Length)]);
            // 打乱顺序，避免总是“字母+数字”开头
            char[] arr = sb.ToString().ToCharArray();
            for (int i = arr.Length - 1; i > 0; i--)
            {
                int j = Rnd.Next(i + 1);
                char t = arr[i]; arr[i] = arr[j]; arr[j] = t;
            }
            return new string(arr);
        }
    }
}

登录记录（登入、登出时间）

湖北样题有“登录记录”界面。思路：建一张 LoginLog(LogId, ManagerId, LoginTime, LogoutTime NULL)；登录成功时插入一行并用 SCOPE_IDENTITY() 取回 LogId 存到 Session；注销或退出时 UPDATE LoginLog SET LogoutTime = GETDATE() WHERE LogId = @id。注意：练习库没有这张表，你可以自己用 CREATE TABLE 加上——这也是“题目要求时才可以修改数据库结构”的一个例子。

10风格指引与界面规范

辽宁样卷写明“保持在整个开发过程中使用所提供的风格指引”，湖北评分表在“员工菜单和管理员菜单”中专门有“页面风格符合风格指引”的细项（Logo 和标题位置、每个界面都有 Logo、主色一致）。正式比赛会提供风格指引文件，通常规定：主色/辅色（色值）、字体与字号、Logo 用法、按钮样式等。

做法：把风格集中到一个地方

Style.cs（示例，色值以题目风格指引为准）
using System.Drawing;
using System.Windows.Forms;

public static class Style
{
    public static readonly Color Primary = Color.FromArgb(31, 78, 121);    // 主色
    public static readonly Color Danger  = Color.FromArgb(192, 0, 0);      // 删除 / 取消
    public static readonly Font TitleFont = new Font("微软雅黑", 16F, FontStyle.Bold);
    public static readonly Font BodyFont  = new Font("微软雅黑", 10.5F);

    /// <summary>在每个窗体的构造函数 InitializeComponent() 之后调用一次。</summary>
    public static void Apply(Form f)
    {
        f.Font = BodyFont;
        f.StartPosition = FormStartPosition.CenterScreen;
        foreach (Control c in f.Controls) ApplyTo(c);
    }

    private static void ApplyTo(Control c)
    {
        Button b = c as Button;
        if (b != null)
        {
            bool danger = b.Name.StartsWith("btnDelete") || b.Name.StartsWith("btnCancel");
            b.FlatStyle = FlatStyle.Flat;
            b.BackColor = danger ? Color.White : Primary;
            b.ForeColor = danger ? Danger : Color.White;
        }
        foreach (Control child in c.Controls) ApplyTo(child);   // 递归处理容器里的控件
    }
}
