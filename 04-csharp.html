01准备：建一个控制台项目

  1. VS → 创建新项目 → 搜索“控制台” → 选择“控制台应用(.NET Framework)”（C#）。
  2. 项目名 Ch04，位置 D:\备赛\练习\04-CSharp，框架 .NET Framework 4.8。
  3. 打开 Program.cs，你会看到下面的结构：
Program.cs
using System;

namespace Ch04
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("你好，商务软件！");
            Console.ReadKey();   // 等待按键，防止窗口一闪而过
        }
    }
}

按 F5 运行，黑色窗口里出现“你好，商务软件！”。这就是你的第一个程序。

  • using System;：引入系统命名空间，这样才能直接写 Console。
  • namespace、class：先把它们当成“装代码的盒子”，第 9 节再细讲。
  • static void Main：程序从这里开始执行。
  • 每条语句以分号 ; 结尾；大括号 { } 成对出现；大小写敏感（console 是错的）。
说明：C# 语言版本

.NET Framework 4.8 的项目默认使用 C# 7.3。网上很多新教程用的是 C# 10 以后的写法（例如没有 Main 方法的“顶级语句”、record、new() 省略类型名、switch 表达式），这些在 C# 7.3 中会编译报错。本章所有代码都按 C# 7.3 编写，你可以放心照抄。

训练建议：本章练习的组织方式

每做一个练习，就在 Program 类里新写一个静态方法（如 static void Ex4_1()），在 Main 里调用它。做下一题时把上一题的调用注释掉。这样一个项目就能保存全部练习，方便复习。

练习 4-3　准点率

某航班 30 天内实际执行 28 次，延误 3 次。准点率 = 100% − 延误率，结果四舍五入为整数。输出“准点率：89%”。

参考答案 
int flown = 28, delayed = 3;
double delayRate = (double)delayed / flown;          // 0.10714...
int onTime = (int)Math.Round((1 - delayRate) * 100, MidpointRounding.AwayFromZero);
Console.WriteLine($"准点率：{onTime}%");             // 准点率：89%

练习 4-4　血压分级

输入收缩压和舒张压（整数）。规则（练习用的简化规则）：收缩压 ≥140 或舒张压 ≥90 为“偏高”；收缩压 <90 或舒张压 <60 为“偏低”；其余为“正常”。输入非数字时提示重新输入。测试：150 85 → 偏高；85 55 → 偏低；120 80 → 正常。

参考答案 
static string BloodLevel(int sys, int dia)
{
    if (sys >= 140 || dia >= 90) return "偏高";
    if (sys < 90 || dia < 60) return "偏低";
    return "正常";
}

先判断“偏高”再判断“偏低”，顺序不同可能导致结果不同。思考：收缩压 150、舒张压 55 应该算什么？按上面的规则是“偏高”。真实比赛中如果题目规则有重叠，要按题目原文的先后顺序实现。

练习 4-5　登录三次锁定

正确密码是 abc12345。循环读入密码，最多 3 次：正确输出“登录成功”并结束；错误输出“密码错误，还剩 N 次”；3 次都错输出“已锁定”。

参考答案 
const string Correct = "abc12345";
bool success = false;
for (int i = 1; i <= 3; i++)
{
    Console.Write("密码：");
    if (Console.ReadLine() == Correct) { success = true; break; }
    if (i < 3) Console.WriteLine($"密码错误，还剩 {3 - i} 次");
}
Console.WriteLine(success ? "登录成功" : "已锁定");

湖北样题的“登录失败 3 次后出现验证码”就是这个逻辑的变形：用一个计数变量记录失败次数。

练习 4-6　分页计算

共有 47 条记录，每页 10 条。用循环输出每一页的记录序号范围：“第 1 页：1–10” …… “第 5 页：41–47”。再输出总页数。

参考答案 
int total = 47, pageSize = 10;
int pages = (total + pageSize - 1) / pageSize;     // 向上取整：5
for (int p = 1; p <= pages; p++)
{
    int from = (p - 1) * pageSize + 1;
    int to = Math.Min(p * pageSize, total);
    Console.WriteLine($"第 {p} 页：{from}–{to}");
}
Console.WriteLine($"共 {pages} 页");

这两个公式（总页数向上取整、每页起止）在比赛的分页功能里会反复用到，抄进错题本。

逐个字符判断

static bool HasLetterAndDigit(string pwd)
{
    bool hasLetter = false, hasDigit = false;
    foreach (char c in pwd)
    {
        if (char.IsDigit(c)) hasDigit = true;
        else if ((c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z')) hasLetter = true;
    }
    return hasLetter && hasDigit;
}
易错提醒

char.IsLetter('张') 也返回 true——汉字也算“字母”。题目要求“含字母”通常指英文字母，所以上面用范围判断。

正则表达式（Regex）

正则表达式是描述“字符串格式”的小语言。比赛中最常见的校验都可以一行搞定。需要 using System.Text.RegularExpressions;

校验写法说明
11 位数字^\d{11}$^ 开头、$ 结尾，中间恰好 11 个数字
手机号（1 开头）^1\d{10}$题目只说“11 位”时，用上一行即可，不要自己加严
密码 ≥8 位且含字母和数字^(?=.*[A-Za-z])(?=.*\d).{8,}$(?=…) 表示“后面某处必须出现”
6 位数字验证码^\d{6}$
简单邮箱^[^@\s]+@[^@\s]+\.[^@\s]+$够用即可，不追求完美
日期 YYYY-MM-DD用 DateTime.TryParseExact比正则可靠，能排除 2 月 30 日
using System.Text.RegularExpressions;

bool okPhone = Regex.IsMatch("13800138000", @"^\d{11}$");                     // true
bool okPwd = Regex.IsMatch("abc12345", @"^(?=.*[A-Za-z])(?=.*\d).{8,}$");      // true
bool badPwd = Regex.IsMatch("12345678", @"^(?=.*[A-Za-z])(?=.*\d).{8,}$");     // false

字符串前面的 @ 表示“原样字符串”，里面的反斜杠不需要再转义。

练习 4-7　注册校验器

写一个方法 static string ValidateRegister(string user, string pwd, string pwd2, string phone)，返回第一条错误信息，全部通过返回空字符串 ""。规则：用户名不能为空；密码 ≥8 位含字母和数字；两次密码一致；电话 11 位数字。用以下数据测试并写出预期输出：

  1. ("", "abc12345", "abc12345", "13800138000")
  2. ("wang", "abc123", "abc123", "13800138000")
  3. ("wang", "abc12345", "abc12346", "13800138000")
  4. ("wang", "abc12345", "abc12345", "1380013800")
  5. ("wang", "abc12345", "abc12345", "13800138000")
参考答案与预期结果 
static string ValidateRegister(string user, string pwd, string pwd2, string phone)
{
    if (string.IsNullOrWhiteSpace(user)) return "用户名不能为空";
    if (!Regex.IsMatch(pwd ?? "", @"^(?=.*[A-Za-z])(?=.*\d).{8,}$")) return "密码至少 8 位，且必须同时包含字母和数字";
    if (pwd != pwd2) return "两次输入的密码不一致";
    if (!Regex.IsMatch(phone ?? "", @"^\d{11}$")) return "联系电话必须是 11 位数字";
    return "";
}

预期：① 用户名不能为空；② 密码至少 8 位……；③ 两次输入的密码不一致；④ 联系电话必须是 11 位数字；⑤ 空字符串（通过）。这个方法第 06 章会直接搬进注册窗体。pwd ?? "" 的意思是“如果 pwd 是 null 就用空字符串”，防止空引用异常。

08方法：把重复的事情写一次

// 返回值类型 方法名(参数列表)
static decimal CalcAmount(decimal unitPrice, int quantity, bool isVip)
{
    decimal amount = unitPrice * quantity;
    if (isVip) amount = amount * 0.9m;
    return Math.Round(amount, 2, MidpointRounding.AwayFromZero);
}

// 调用
decimal a = CalcAmount(128.5m, 3, true);   // 346.95
  • 方法名用大驼峰（PascalCase）：CalcAmount、LoadUsers。
  • 一个方法只做一件事，长度最好不超过一屏。
  • 没有返回值写 void。
  • out 参数可以“多返回一个值”，TryParse 就是这样设计的。
易错提醒：金额舍入

Math.Round(2.345m, 2) 默认用“银行家舍入”（遇 5 取偶），结果是 2.34 而不是 2.35。题目说“四舍五入”时，一定写 Math.Round(x, 2, MidpointRounding.AwayFromZero)。同时金额要用 decimal，不要用 double。

预期结果

2.34、2.35、2、4。后两个说明默认舍入“遇 5 取偶”。

练习 4-10　订餐补差价

写方法 static decimal Diff(decimal oldTotal, decimal newTotal) 返回差额（新 − 旧）。再写一个方法把差额格式化：正数显示“需补交 X 元”，负数显示“退款 X 元”（X 为绝对值，保留 2 位），0 显示“无需补退”。（湖北样题订餐服务中有类似要求：退款时金额为负数并标识为退款。）

参考答案 
static string DiffText(decimal oldTotal, decimal newTotal)
{
    decimal d = newTotal - oldTotal;
    if (d > 0) return $"需补交 {d:0.00} 元";
    if (d < 0) return $"退款 {Math.Abs(d):0.00} 元";
    return "无需补退";
}

插值中的 {d:0.00} 等同于 d.ToString("0.00")。

09类与对象

类是“模板”，对象是按模板造出来的“东西”。在比赛中，数据库的每张表通常对应一个类，叫“实体类”或“模型类”。

Models.cs
public class Service
{
    // 属性：大驼峰命名，{ get; set; } 是自动属性
    public int Id { get; set; }
    public string Name { get; set; }
    public decimal Price { get; set; }
    public int DurationMinutes { get; set; }
    public bool IsOnSale { get; set; }

    // 构造函数：创建对象时自动执行
    public Service() { IsOnSale = true; }

    public Service(int id, string name, decimal price)
    {
        Id = id; Name = name; Price = price; IsOnSale = true;
    }

    // 方法
    public string PriceText()
    {
        return Price.ToString("0.00") + " 元";
    }

    // 重写 ToString：在下拉框中显示对象时会用到
    public override string ToString()
    {
        return Name;
    }
}
使用
Service s1 = new Service(1, "助浴", 120m);
Service s2 = new Service { Id = 2, Name = "陪诊", Price = 200m };   // 对象初始化器
s2.Price = 180m;
Console.WriteLine(s1.PriceText());    // 120.00 元
Console.WriteLine(s2);                // 陪诊（自动调用 ToString）

List<Service> list = new List<Service> { s1, s2 };

练习 4-11　订单类

public class Order

    public int Id { get; set; }
    public string CustomerName { get; set; }
    public string ServiceName { get; set; }
    public decimal UnitPrice { get; set; }
    public int Quantity { get; set; }
    public DateTime AppointmentTime { get; set; }
    public OrderStatus Status { get; set; }

    public decimal Amount { get { return UnitPrice * Quantity; } }

    public bool CanCancel()
    {
        bool statusOk = Status == OrderStatus.Pending || Status == OrderStatus.Paid;
        bool timeOk = AppointmentTime > DateTime.Now.AddHours(2);
        return statusOk && timeOk;
    }
}

10异常处理

程序运行中出现无法继续的问题（数据库连不上、文件不存在、除以零），就会“抛出异常”。不处理，程序就崩溃——在比赛中，一次崩溃可能让裁判后面的测试全部无法进行。

try
{
    int x = int.Parse("abc");          // 这里会抛出 FormatException
    Console.WriteLine("不会执行到这里");
}
catch (FormatException)
{
    Console.WriteLine("格式不正确");
}
catch (Exception ex)                   // 兜底：捕获其他所有异常
{
    Console.WriteLine("发生错误：" + ex.Message);
}
finally
{
    Console.WriteLine("无论是否出错都会执行");   // 常用于关闭连接
}

主动抛出异常：throw new ArgumentException("数量必须大于 0");

训练建议：异常处理的分寸
  • 能预判的错误，用 if 判断，不要靠异常：用户输入格式用 TryParse 和正则；除数先判断是否为 0。
  • 无法预判的错误，用 try-catch 兜住：数据库操作、文件读写、网络请求。
  • catch 里要给用户一个能看懂的提示，不要什么都不做（“吞掉异常”会让你调试时找不到问题）。
练习 4-12　安全除法

读入两个整数，输出商（保留 2 位小数）。分别处理：输入不是数字、除数为 0。要求程序在任何输入下都不崩溃。

11日期与时间

比赛中日期出现频率极高：注册时间、预约时间、验证码有效期、“仅显示今天及以后的日期”、按月统计……

DateTime now = DateTime.Now;
DateTime today = DateTime.Today;                 // 今天 00:00:00
DateTime d = new DateTime(2026, 3, 15, 9, 30, 0);
string s1 = d.ToString("yyyy-MM-dd");            // 2026-03-15
string s2 = d.ToString("yyyy-MM-dd HH:mm");      // 2026-03-15 09:30（HH 是 24 小时制）
string s3 = d.ToString("yyyy-MM");               // 2026-03（按月统计用）
DateTime later = d.AddDays(7).AddHours(-1);
TimeSpan span = later - d;
double hours = span.TotalHours;                  // 167
bool expired = (DateTime.Now - d).TotalSeconds > 60;   // 是否超过 60 秒

DateTime parsed;
bool ok = DateTime.TryParseExact("2026-02-30", "yyyy-MM-dd",
    System.Globalization.CultureInfo.InvariantCulture,
    System.Globalization.DateTimeStyles.None, out parsed);   // false：2 月没有 30 日
易错提醒

格式串大小写含义不同：MM 是月、mm 是分钟；HH 是 24 小时制、hh 是 12 小时制。写成 yyyy-mm-dd 是最常见的错误之一，显示出来的“月份”其实是分钟数。

练习 4-13　年龄计算

输入出生日期（yyyy-MM-dd），计算周岁（今年生日没过要减 1）。输入格式不对时提示。用 1950-12-31 和今天的日期分别测试。

参考答案 
static int Age(DateTime birth, DateTime today)
{
    int age = today.Year - birth.Year;
    if (birth.Date > today.AddYears(-age)) age--;
    return age;
}
练习 4-14　7 天自动登录

假设上次登录时间保存为字符串 "2026-11-05 08:00:00"。写方法判断当前时间是否仍在 7 天内（湖北样题的“Auto login in 7 days”）。

参考答案 
static bool WithinDays(string lastLogin, int days)
{
    DateTime t;
    if (!DateTime.TryParseExact(lastLogin, "yyyy-MM-dd HH:mm:ss",
        System.Globalization.CultureInfo.InvariantCulture,
        System.Globalization.DateTimeStyles.None, out t)) return false;
    return DateTime.Now < t.AddDays(days);
}

12LINQ：像写 SQL 一样处理集合

LINQ 让你对 List 做筛选、排序、统计，写法简洁。需要 using System.Linq;（新建项目默认已有）。

List<Service> list = new List<Service>
{
    new Service(1, "助浴", 120m), new Service(2, "陪诊", 200m),
    new Service(3, "助餐", 25m),  new Service(4, "康复理疗", 260m)
};

var cheap = list.Where(s => s.Price < 150m).ToList();               // 筛选
var sorted = list.OrderByDescending(s => s.Price).ToList();         // 排序（降序）
var names = list.Select(s => s.Name).ToList();                       // 只取名字
decimal total = list.Sum(s => s.Price);                              // 求和 605
int count = list.Count(s => s.Price > 100m);                         // 计数 3
Service first = list.FirstOrDefault(s => s.Name.Contains("陪"));     // 找不到返回 null
bool any = list.Any(s => s.Price > 250m);                            // true

// 分页：第 2 页，每页 2 条
var page2 = list.OrderBy(s => s.Id).Skip(2).Take(2).ToList();

// 分组统计
var groups = list.GroupBy(s => s.Price >= 150m ? "高价" : "普通")
                 .Select(g => new { Kind = g.Key, Num = g.Count(), Sum = g.Sum(x => x.Price) })
                 .ToList();
foreach (var g in groups) Console.WriteLine($"{g.Kind}: {g.Num} 项，合计 {g.Sum}");

s => s.Price < 150m 叫 Lambda 表达式，读作“对每个 s，判断它的价格是否小于 150”。
